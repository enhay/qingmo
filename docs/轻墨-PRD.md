## 1. 背景与目标

**问题**：在思源手机端记一个闪过的念头，要先打开 App，找到文档，进入编辑器，再定位光标，步骤太多，所以碎片想法都记到了 flomo 里，散落在思源之外。flomo 体验好，但数据不在自己的笔记系统里，没法和思源里的知识做引用、搜索和回看。

**目标**：轻墨要在思源手机端提供 flomo 那样的体验——打开就能写，写完就走，之后用卡片流回看——并且每条速记都是思源的原生块。

**自用期的成功标准**：

1. 开启"启动后直接进入轻墨"后，冷启动思源 2 秒内就能打字，不需要任何点击；没开启时，从思源主界面进入输入最多点 1 次。
2. 点发送后 1 秒内可在卡片流看到保存结果；默认倒序时出现在非置顶组顶部，有筛选或其他排序时遵循当前条件，不伪造不符合条件的卡片。
3. 连续用 4 周，新的碎片想法全部记在思源里，不再打开 flomo。

**远期目标**：自己用顺手以后付费公开。这对一期有三条约束：

- 属性名带插件专属前缀；
- 界面文字全部走 i18n 文件，不在代码里写死；
- 不写死任何个人路径、笔记本或凭据。

| 场景 | 现在怎么做 | 用了轻墨以后 |

| 围绕一个主题回顾或理解近期变化 | 在多处筛选、复制材料 | 回顾单独选择标签与日期；AI 洞察先确认材料，再生成带原始笔记来源的结果 |

### 3.1 对齐 flomo 的方式

按用户可完成的动作对齐，不复制另一套数据系统。2026-10-13 对本机 flomo 5.26.93 的安装包进行了静态检查：标签树接入常用、重命名和移动操作；卡片接入置顶、引用批注与复制链接；每日回顾请求带标签、时间、数量参数；AI 模板从服务端读取，洞察任务提交模板 ID 并接收服务端结果。这些是客户端代码证据，不代表当前账号权益、云端结果或所有设备已验证。

| flomo 的动作或能力 | 轻墨如何提供 | 边界 |
|---|---|---|
| 折叠标签、查找标签、固定常用主题 | 在现有标签树上操作，见 6.2 | 不创建第二套正文标签；不批量重命名、移动或删除标签 |
| 笔记置顶、取消置顶 | 在符合当前筛选的卡片中优先展示，见 6.3 | 不改变创建时间、统计或回顾抽样权重 |
| 复制笔记链接、引用后补充想法 | 思源块链接与原生块引用，见 6.4 | 不建专用批注数据库；反向引用由思源承载 |
| 自定义每日回顾材料 | 独立选择标签和日期，见 6.5 | 默认全部；不跟随卡片流筛选，不加提醒推送 |
| 单条及多条 AI 洞察、选择视角、查看历史结果 | 本地方法文件 + 思源配置的模型 + 原生结果文档，见 6.6 | 不调用 flomo 私有服务，不宣称取得官方完整提示词 |
| 随机漫步、相关笔记 | 保持本地随机翻阅 | 本次不增加语义推荐、向量索引或关联游走 |
| 笔记历史、回收、附件、同步与导出 | 复用思源历史、资源、同步和导出；轻墨已有单条历史入口 | 不承诺独立历史期限、附件备份或同步冲突解决系统 |
| 语音速记 | 输入框录音，用户自己的腾讯云一句话识别转写，见 6.7 | 单段 60 秒；不做边说边出字、不做语音摘要 |
| 批量整理、分享图片、导入 | 本次不新增 | 不因 flomo 中存在就自动列入交付 |

## 4. 数据模型（已定，以后改要做数据迁移）

### 4.1 每日文档

- 每天的速记放在一个独立文档里，**不写进思源日记**。
- 位置 = 笔记本 + 路径模板。默认模板是 `/轻墨/{yyyy}/{MM}/{yyyy-MM-dd}`，文档标题就是日期。第一次使用时让用户选笔记本（你自用时选「碎碎念」），不预设任何笔记本。
- 文档上加属性 `custom-qingmo-day="20261011"`。写入时先按这个属性找当天的文档，找不到再按路径找，都找不到就新建。这样用户把文档挪了位置或改了名字，也不会再多建一个。
- 归属哪一天按**发送时手机的本地日期**算。

### 4.2 每条速记

- 轻墨新建的速记是一个超级块（`{{{row … }}}`），块属性 `custom-qingmo-memo="1"`。已有内容收录保持原块类型，整篇文档也可通过文档标签收录，规则见 6.1；不能把所有收录内容重建为超级块。超级块里可以放多个段落、图片、列表和录音（思源原生音频块，文件在 assets）。尚未转写的音频块带 `custom-qingmo-transcribe="pending"`，转写成功后清除，见 6.7。
- 写入时一次调用 `appendBlock` 完成，Markdown 内容如下：

  ```
  {{{row
  正文第一段 #读书#

  ![](assets/xxx.png)
  }}}
  {: custom-qingmo-memo="1"}
  ```

- **时间**：用块自带的 `created`，不另外存时间字段。
- **标签**：用户输入的 `#标签` 后面接空格、换行或到结尾时，保存时转成思源的 `#标签#`。支持多级标签 `#a/b`。
- **编辑**：用 `updateBlock` 写回 Markdown，保留原 ID、原类型及当前属性。轻墨原生速记保留 `custom-qingmo-memo`；仅凭标签收录的内容不能因编辑而补加该属性。普通段落不能在轻墨内改成多段或容器结构；复杂内容在思源中编辑。
- **删除**：仅原生轻墨卡片使用 `deleteBlock`，删除前确认并说明思源文件历史恢复方式。外部收录内容提供「移出轻墨」，保留原文，见 6.1。
- **在编辑器里直接改**：按当前收录属性和标签重新判断是否进入卡片流；不因位置或曾经是超级块而永久收录。拆分后没有任何收录标记的内容不再显示，但仍留在原文档。
- **只认属性和 `#轻墨` 标签，不按位置收录**：一期只有带 `custom-qingmo-memo` 属性的块进卡片流、搜索和统计；用户在每日文档里直接打的字、同一笔记本里的其他笔记都不算。二期增加两种方式（见第 6 节）：用户手动「加入轻墨」，加入的块额外带 `custom-qingmo-added="1"`，用来区分删除方式；以及带 `#轻墨` 标签的块自动算作速记，不写属性。

### 4.3 统计口径

| 指标 | 怎么算 |
|---|---|
| 笔记数 | 按 6.1 收录与去重后的卡片总数，包含属性、正文标签及文档标签收录 |
| 标签数 | 当前收录集合正文及文档标签中实际出现的完整标签名去重数；仅为树形展示补出的父路径不额外计入 |
| 天数 | 今天减去当前集合中第一条速记的创建日期，再加 1；空集合为 0。这是日历跨度，不是有记录的日期数 |
| 热力图 | 最近 12 周每天的速记条数，颜色分 4 档 |

侧栏统计不随卡片流临时筛选变化。标签树父节点的条数包括该标签及子标签，并按卡片 ID 去重；同一卡片同时含 `a/b`、`a/c`，父节点 `a` 只增加一条。置顶、常用标签和 AI 结果不另增速记数量；AI 结果只有被用户显式收录时才参与。

### F1 入口

### F2 输入面板（对照截图 3）

| 编号 | 需求 | 验收 |
|---|---|---|
| F2.1 | 底部固定一条输入栏，提示文字"点击输入"；点击后展开为贴在键盘上方的输入面板，提示文字"现在的想法是…" | 键盘弹出后面板完整可见，不被键盘或思源的键盘工具栏挡住 |

| F2.4 | 图片：从相册选或拍照，可以选多张，**选中后立即上传**到 assets，以缩略图显示在面板里，能删掉。草稿被放弃或图片被删掉后，留下的未引用图片由思源自带的"清理未引用资源"处理，轻墨不自己删文件 | 发送后图片在这条速记的超级块里，在思源编辑器里能正常显示 |
| F2.5 | 内容为空（只有空格，也没有图片）时发送按钮置灰 | — |
| F2.6 | 草稿只存在本机 WebView 的 `localStorage` 里，**不同步、不写成块**。新建用键 `qingmo:draft:new`，编辑已有速记用 `qingmo:draft:<块ID>`；内容是正文加已上传图片的路径。停止输入 300ms 后保存一次，发送成功后删除，发送失败时保留。读写都包在 `try/catch` 里，失败时只是这次没有草稿，不影响记录 | 关掉面板、切到后台、杀掉 App 后重开，草稿都还在；同时编辑两条速记，两份草稿互不覆盖；草稿内容不出现在思源的搜索结果里 |
| F2.7 | 发送：写入当天文档，移动面板成功后收起，桌面内嵌输入区清空并保留；刷新后按当前筛选和排序展示。若新卡片不符合当前条件，提示保存成功且当前筛选未显示，提供返回全部记录的入口；失败保留内容并提示"没有保存成功，内容还在输入框里" | 断开内核连接时发送，内容不丢；置顶及来源筛选不造成保存结果误判 |

| F4.4 | 标签列表：多级标签显示成树，后面带条数 | — |
| F4.5 | 设置入口 | — |

### F5 搜索

关键词按连续文本包含匹配，可以与标签（含子标签）、图片／链接／无标签、单日和来源条件叠加。结果仍以卡片流显示，条件可逐项移除或清空；关闭搜索框不取消关键词。第二段及整篇收录笔记标题后的正文也必须可搜索。

顶部菜单支持创建时间正序／倒序及全部／轻墨速记／收录笔记。二期加入置顶后按 6.3 排序。标签查找只缩小侧栏标签列表，不改变笔记搜索；每日回顾与 AI 的范围选择也不改写卡片流条件。本次不改为多关键词语法、不加入搜索标签排除或日期区间。

桌面端与手机端布局分开，参照 flomo 客户端：顶栏图标和快捷键在思源标签页里打开轻墨，宽度够时是两栏布局（左侧统计、热力图、筛选和标签常驻，右侧标题、搜索框、内嵌输入框和卡片流）；快捷键打开后直接聚焦输入框。右侧栏（`addDock`）宽度不够两栏，沿用手机布局。布局规格见 [design](design/轻墨-design.md) 2.6。

## 6. 二期功能细则

本节区分已交付基础与本次增补。范围已确认不代表实现已完成；执行顺序、验证前提及状态统一见[二期计划](plans/2026-10-12-phase-two.md)。

### 6.1 已有笔记收录（已交付，后续功能共用）

- **手动收录**：思源块菜单「加入轻墨」只设置 `custom-qingmo-memo="1"`、`custom-qingmo-added="1"`；不移动、不包装、不改正文。文档本身、已收录块及其内部子块不提供重复加入。
- **正文标签**：精确的原生 `#轻墨#` 是开关，不写收录属性。代码、普通文字、链接字面值与 `轻墨/子标签` 不视为开关。标签段落直接属于列表项、引用或超级块时收入该直接容器；标题只收入自身。嵌套和重复命中按现有集合逻辑归并到已收录外层，不能拆成重复卡片。
- **文档标签**：文档顶部标签精确包含「轻墨」时整篇为一张卡片，内部独立收录暂不重复展示；去掉文档标签后内部已收录内容恢复展示。卡片含标题和正文预览，时间取文档创建时间。
- **同一集合**：列表、搜索、统计、标签树、回顾与 AI 材料查询均消费上述集合，按块 ID 去重，沿用原生 `created`，不按目录自动收录。
- **来源与编辑**：外部块显示来源并能定位原文；段落与超级块仅在当前安全编辑范围内写回，整篇文档及复杂结构回思源编辑。仅凭标签收录的内容删除最后一个收录标签前提示其将离开轻墨。
- **移出**：手动收录清除两项收录属性，标签收录去掉对应精确标签，两种方式并存则确认后同时清除。整篇收录仅移除文档标签。保留原 ID、位置、其余属性、其余正文和子块，不删除原文，不误改代码或链接中的同名字样。

### 6.2 标签导航（本次增补）

| 动作 | 行为与可观察结果 |
|---|---|
| 展开／折叠层级 | 有子标签的节点可独立展开；点展开控件不触发笔记筛选，点标签名称沿用含子标签筛选。默认展开以延续现有可见内容；用户折叠状态在本设备重开后保留 |
| 查找标签 | 标签区独立输入框按完整路径做大小写不敏感的包含匹配；显示命中标签和必要父路径，临时展开到命中处。清空后恢复原展开状态；不改变卡片流关键词和其他条件 |
| 查看无匹配结果 | 提示没有匹配标签，保留输入及清空入口；不把卡片流变成空结果 |
| 加入／取消常用 | 从标签操作入口切换；常用区是现有标签的快捷入口，带完整路径与现有条数，点击仍走同一个筛选。相同标签只出现一次，按加入顺序排列；本次不提供拖拽排序 |
| 标签消失或在思源中改名 | 常用区只展示当前集合中存在的原完整路径；旧偏好不自动猜测新名称，也不重写原文。原路径再次出现时仍按已有偏好展示 |
| 设置与同步 | 常用标签存于插件现有设置，沿用思源插件数据同步；标签搜索内容与树展开状态仅属本设备界面状态，不同步正文或另建标签库 |

父标签数量及默认筛选语义沿用 4.3、F5。所有菜单支持键盘访问、焦点返回和移动触控。本次不提供重命名、合并、移动、删除标签或批量给笔记加标签；这些会修改思源原文，不属于已授权增补。

### 6.3 笔记置顶（本次增补）

- 卡片菜单提供「置顶／取消置顶」，卡片有可识别的置顶状态。原生速记、外部块及整篇收录文档都可操作，写入对象就是当前卡片对应的原生块。
- 使用块属性 `custom-qingmo-pinned="1"` 表示置顶；取消时清除该属性。此属性只影响排序，不会单独触发收录；现有无此属性的内容自然视为未置顶，无需批量迁移。
- 先按全部筛选条件选出集合，再把其中置顶卡片排在前面。置顶组与普通组内都沿用用户选择的创建时间正序／倒序，同时间按块 ID 同向排序；分页基于完整排序，不能只对已加载页面排序。
- 置顶不改变正文、创建时间、原位置、收录方式和统计，也不提高回顾或 AI 取样权重。重新编辑、历史恢复不能意外清除当前置顶属性。
- 移出轻墨后不再显示该卡片，置顶偏好留在原块；再次收录时恢复置顶。删除原块则随原块消失。同步后的状态以思源块属性为准，不新增冲突合并机制。
- 保存失败时保留原状态并提示失败；从原生 API 读回属性，并经列表筛选、跨页和重开验证真实排序。

### 6.4 复制块链接与引用续写（本次增补）

| 动作 | 行为与边界 |
|---|---|
| 复制链接 | 卡片菜单复制 `siyuan://blocks/<当前卡片ID>`；整篇卡片复制文档 ID。保留已有「复制文本」，不复制网页分享链接 |
| 引用续写 | 打开新建速记输入框，插入指向原卡片的思源原生块引用，光标位于后面的空段落；不复制原笔记全文，不修改原笔记，不沿用原笔记日期或标签 |
| 已有新建草稿 | 确认后才用引用续写替换当前新建草稿；取消则草稿不变。当前正在编辑的笔记继续按原 ID 保留草稿，不被转成新建内容 |
| 发送及再次编辑 | 新速记按发送时日期落入现有每日文档，获得新 ID；引用仍指向原 ID。草稿、预览、发送、再编辑和历史恢复都保留引用，不退化成纯文本或普通链接 |
| 打开引用／查反向引用 | 点击引用能在思源定位来源；反向引用和进一步组织使用思源原生面板，不建轻墨专用批注关系表或评论线程 |
| 来源变化 | 原文移出轻墨不使引用失效；原块删除后沿用思源失效引用行为，不把已删除正文复制回来，也不自动外发寻找替代来源 |

引用续写支持范围是思源原生块引用，不扩展为任意嵌入或完整原生编辑器。现有编辑器暂不支持该结构；实现前先证明引用的序列化、草稿及真实内核往返。如果无法保真，不以静默去掉引用交付，也不顺带放宽其他复杂块的编辑限制。

### 6.5 本地回顾与随机漫步

**每日回顾增强**：设置在回顾页独立维护，默认全部内容；不继承卡片流筛选，不调用 AI。

| 项目 | 确定行为 |
|---|---|
| 标签范围 | 默认全部，可选择一个标签，包含该标签及子标签；沿用标签树计数与匹配语义。本次不增加多标签交并、排除标签或无标签专用模式 |
| 日期范围 | 可单独设置开始／结束日期，空端表示不限；按原生创建日期包含首尾两天。开始晚于结束时不能应用，并提示修正 |
| 组合 | 标签与日期取交集，作用于 6.1 的完整集合，不能只从当前加载页面抽样 |
| 范围与数量设置 | 范围和条数通过插件现有设置保存；默认条数沿用当前值。展示已应用范围，取消编辑不改变现有回顾 |
| 同日稳定 | 同设备、同本地日期、同一标签与日期范围保持已有抽取 ID 和顺序；数量只取这一顺序的前 N 条。切换范围分别记忆，当天切回来仍恢复原顺序 |
| 材料变化 | 新加入且符合范围的笔记排在已有顺序之后；已删除、移出或不再符合范围的笔记剔除。取前 N 条时可补入尚未展示的有效内容，不保留失效正文 |
| 空集合／不足条数 | 显示实际数量；无内容时显示当前范围与调整入口，不能偷偷退回全部笔记 |
| 跨日与跨设备 | 新的本地日期使用新的抽样；抽取 ID 只存本机，不承诺不同设备的抽取进度一致。跨午夜重新进入或刷新时以新日期为准 |
| 阅读动作 | 完整正文、上一条／下一条、左右滑动、位置提示、原生定位；沿用卡片通用操作，不为回顾另写编辑或删除逻辑。退出保留卡片流条件和未发送草稿 |

**随机漫步保持原义**：从全部当前收录内容随机展示一条，多个候选时避免连续重复，单条时仍可阅读；不继承每日回顾范围或卡片流筛选。没有关联推荐、路径图、语义搜索或提醒推送。

### 6.6 AI 洞察（本次接入）

#### 6.6.1 入口、视角与范围

- 视角列表保留「每日回顾」「随机漫步」两个本地功能，并接入 `default` 默认洞察、`values` 价值澄清、`inversion` 逆向思考、`second-order` 二阶思考、`cbt` CBT、`mbti` MBTI 六个已有方法；本地回顾不标成 AI 生成。
- 卡片菜单「AI 洞察」以该卡片为材料；视角列表入口可选择全部收录内容，或用一个含子标签的标签与开始／结束日期限制材料。默认全部，生成前明确显示范围；不默默继承列表或回顾条件。
- 选择视角后可填写具体问题；需要目标或困扰的方法应给出对应引导，不强制所有视角填写问题。本次不接入自定义视角编辑、云端模板市场、自动分析或多轮聊天。
- 生成前显示所选模型、匹配笔记数、实际发送数、实际日期范围，以及因长度限制未发送的情况；明确材料将交给思源中配置的 AI 服务。只有点击「开始洞察」才调用模型；切换视角、打开范围和预览材料均不调用。
- 空集合、全部材料无可分析文字、未配置编辑模型、无可用结果笔记本时不发起生成，并提供调整范围、打开 AI 设置或选择笔记本的入口。纯图片不假装已完成识别，已有文字说明仍可作为材料。

#### 6.6.2 材料与提示词

- 方法唯一来源是项目内 [qingmo-insights](../skills/qingmo-insights/SKILL.md) 及当前视角对应 Reference；六个方法的公开来源见 [sources.md](../skills/qingmo-insights/references/sources.md)。不从 flomo 抽取或调用官方提示词，不在界面配置和代码中再维护另一份方法正文。
- 构建产物必须包含这些本地资源。配置使用 `{id, title, author, description, kind, reference, needsScope}`；按视角 ID 固定映射读取，不能接受用户传入的任意路径或 URL。资源缺失是加载失败，不能退回无方法的通用生成。
- 插件按 6.1 查询当前真实材料，提供每条的原始块 ID、创建时间、标签、正文和明确条目分界。方法说明、用户问题与笔记正文分开组织；笔记中的命令、角色声明和链接仅作为材料，不执行、不跟随。
- 多条按创建时间从新到旧选择，默认正文总量上限 3 万字；以完整条目为单位取最近的前缀，不在单条中途截断，也不跳过较新的超长条目后冒称最近完整范围。第一条即超限时提示缩小或拆分材料，不发起空请求。单条洞察超限同样提示。上限是可调实现参数，不保证适配任意模型上下文窗口。
- 单条读取失败不得当作没有笔记或静默漏掉；保留条件并提示重新读取。发起请求以最后确认的材料快照为准，不在生成途中追加入库内容；只发送文本，不上传图片和音频文件，不自动展开引用目标或读取范围外的笔记。
- 来源使用 `[日期](siyuan://blocks/原始ID)`；主要判断应有实际材料支持，不能虚构身份、日期或长期模式。将输出中的来源 ID 与本次输入集合核对；不存在于材料中的来源不得作为有效引用展示或自动归档，应提示重新生成。
- CBT 是自助反思、MBTI 是非正式偏好观察，遵守已有方法文件的心理边界，不宣称诊断或治疗。结果只根据已提供材料分析，省略或长度限制必须说明。

#### 6.6.3 模型调用、取消与失败

- 复用思源「设置 → AI」的编辑模型和超时配置；密钥由思源管理，不复制到插件设置，不指定个人模型名或固定超时。费用由用户自己的 AI 账号承担，与录音转写的腾讯云配置无关。
- 沿用已定的 `POST /api/ai/chatGPT {msg}`：调用前清理共用上下文，发送已拼好的完整材料，调用结束后清理。接口非流式，只显示真实的准备／生成／保存状态，不伪造进度或打字流。
- 同一插件实例的标签页、侧栏和移动入口共用一次进行中的洞察状态；因为这些入口使用同一个内核上下文，已有请求未结束及清理前不并发发起第二次。此约束不解决其他插件同时调用的干扰，既定的跨插件共用上下文风险仍存在，不声称请求隔离。
- 「取消」立即退出等待，丢弃之后到达的结果，不创建结果文档；旧接口没有可靠的服务端取消能力，不能声称模型已停止或不再计费。仍需等待内核请求完成后清理上下文，避免只在取消瞬间清理、随后旧请求又写回历史。插件卸载或进程终止时不承诺清理必达，下次调用前仍清理。
- 非零响应、网络失败以及生成请求返回空字符串都按失败处理；保留范围、问题与视角供用户主动重试，不自动重新计费调用。清理上下文操作本身返回空字符串不属于生成失败。
- 生成成功与文档保存分开处理：保存失败保留已经生成的结果供复制和重试保存，不能通过重新调用模型来重试保存。接口不能可靠提供输出是否被模型长度截断的标志，不宣称每次返回都是完整报告；记录并展示宿主给出的限制信息。

接口依据：[SiYuan 3.8.6 的 AI 实现](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/model/ai.go)。这里确认的是该版本源码行为，实际目标宿主配置、手机进度提示与请求结束后的清理仍需实现时验证。本次不切换 `chatGPTWithAction` 或带内置编辑提示词的 SSE 接口。

#### 6.6.4 结果、再次洞察与历史

- 完成后在页面显示范围说明、视角、实际材料数量、生成时间、正文与可定位来源；不是把输入全文再复制一遍。显示和保存继续过滤危险 HTML、脚本及 URL。
- 沿用原定自动保存：在已选轻墨笔记本下创建 `/轻墨/洞察/{yyyy-MM-dd}-{视角名}`，加 `custom-qingmo-insight="<视角ID>"`；同日同名再次生成使用唯一后缀创建新文档，不能覆盖既有洞察。生成前缺少笔记本就先选择。
- 结果不加速记收录属性或「轻墨」标签；正文中为说明范围展示的标签用普通文字或代码，不能意外变成自动收录开关。用户需要纳入回顾时再显式收录。
- 页面提供「在思源中打开」「复制结果」「再次洞察」。再次洞察回到范围确认，重新读取当前材料；不自动携带前一次模型回答，也不改写前一次已保存文档。
- 视角页提供「历史洞察」列表，按结果文档创建时间倒序读取现有属性，显示标题、时间与视角，点击在思源打开。文档移动或改名不失联，删除后不再列出；改写、全文搜索、导出及历史恢复继续使用思源，不建独立洞察数据库或回收站。
- 来源笔记后来移出轻墨仍可按原 ID 定位；删除后提示来源不可用，保留已保存的洞察文本，不编造替代证据。AI 方法更新只影响之后生成，不重写已有结果。

### 6.7 录音与转写（本次增补）

#### 6.7.1 录音

- 手机输入面板和桌面内嵌输入框都有录音按钮。录音中显示计时，可停止或取消；到 60 秒自动停止，提示可以再录一段。一条速记可以有多段录音。
- 停止后立即把原始录音上传到 assets，在草稿里显示为可播放、可删除的音频，规则同 F2.4 图片：草稿存音频路径，放弃草稿或删掉音频后留下的未引用文件由思源"清理未引用资源"处理。取消录音不上传。
- 发送后每段录音是速记超级块里的一个思源原生音频块，在轻墨卡片和思源编辑器里都能播放。再次编辑、草稿恢复、历史恢复都保留音频块及其属性。
- 某个客户端拿不到麦克风（宿主没有麦克风权限、用户拒绝授权、浏览器以非 https 地址访问）时，录音按钮说明原因，不影响其他输入。

#### 6.7.2 转写

- 停止录音后，若已配置密钥，自动转写这一段，文字插入到草稿光标处；用户可以修改后再发送。转写中仍可编辑、继续录音或发送。
- 以下情况速记照常带录音保存，对应音频块标为待转写（`custom-qingmo-transcribe="pending"`），卡片显示"待转写"：没配置密钥、离线、转写失败、转写完成前就发送或关闭输入框。关闭或发送之后才返回的转写结果直接丢弃，不写入任何笔记。
- 卡片菜单"转写录音"只处理这条速记里待转写的音频：逐段识别，把文字作为普通段落写在对应音频块后面，然后清除待转写标记。写入走正常编辑保存，保留历史版本。这条速记正在轻墨里编辑且有未发送草稿时，先提示完成或放弃编辑。每次手动转写都会重新向腾讯云计费，界面要写明。
- 不自动重试，不在后台排队，也不在打开页面时自动转写待转写内容。失败时保留录音和已输入的文字，按原因提示：密钥无效或没有语音识别权限、腾讯云账号欠费或未开通语音识别、录音格式或时长不符合要求、网络失败。
- 识别结果是普通文字，用户发送后与其他正文一样参与搜索、标签和 AI 洞察。AI 洞察不上传音频文件本身。

#### 6.7.3 腾讯云配置与接口

- 设置页"转写"分组填 SecretId 和 SecretKey。显示时打码，只露后 4 位，可以清空。"验证"确认密钥可用并具备语音识别权限，结果直接显示；验证不能产生识别费用。
- 设置页写明三件事：建议使用只授予语音识别权限的 CAM 子账号并设置费用告警；费用由该腾讯云账号承担；密钥随思源同步到所有设备，同一工作空间里的其他插件也能读到。
- 密钥不进日志、错误提示、笔记正文或 AI 材料。
- 接口用腾讯云"一句话识别"（`SentenceRecognition`，中文普通话 16k 引擎，base64 上传）：60 秒以内、编码后不超过 3MB、同步返回文字。它不支持 webm，所以上传前在本机把录音转成 16kHz 单声道 wav；assets 里保存原始录音，不保存转换后的文件。
- 由设备直接请求腾讯云，不经过轻墨的服务器。

### 6.8 保留但不进入本次实施的能力

- **flomo 导入**：保持暂缓，不增加导入入口、原时间属性或迁移代码。重新启动时先确认导出格式与原时间写入方案。
- **高级整理与检索**：标签批量改写、笔记批量操作、多关键词搜索、标签排除、语义相关笔记、分享图片不在本次增补内；既有连续文本搜索和本地随机漫步保持原义。

## 7. 付费与授权（后续再设计）

二期转写由用户自带腾讯云密钥（6.7），不建转写服务、令牌或额度系统。此前"Cloudflare Worker 转写服务＋令牌即激活码"的设计不再是当前方案，需要时从 git 历史取回参考。三期开始做付费功能时，再一并决定授权与激活码怎么做，以及付费用户的转写是继续自带密钥还是由服务端承担。

## 8. 非功能要求

- **离线**：思源内核在本机运行，没网也能记，有网后自动同步。转写需要联网，离线录的音会留在这条速记里，标为"待转写"。
- **隐私**：本地记录、整理和回顾不向外发送笔记。AI 洞察仅在用户确认生成后，将实际选定的文字材料交给思源配置的模型服务；不上传附件，不自动追随引用或读取范围外笔记。录音转写把转换后的音频由设备直接发给用户自己配置的腾讯云语音识别，不经过轻墨的服务器；腾讯云侧的数据处理遵循该账号的服务条款。产品说明分别交代这两条外发路径。
- **外观**：轻墨的全屏层按 [design](design/轻墨-design.md) 的固定配色还原 flomo，只跟随思源的亮色/暗色模式；悬浮按钮、侧滑面板入口、桌面端侧栏用思源的 CSS 变量。
- **无障碍**：所有图标按钮都有 `aria-label`，触控区域至少 44pt，深色和浅色主题下对比度都达到 WCAG AA。
- **兼容性**：`minAppVersion` 定为开发时实测过的最低版本，一期只保证当前稳定版。
- **性能**：5000 条速记时，卡片流首屏不超过 1 秒，热力图查询不超过 300ms；一段 30 秒的录音，从停止录音到文字出现不超过 5 秒（真机实测后再校准）。

## 9. 风险

| 风险 | 影响 | 怎么处理 |
|---|---|---|
| 两台设备往同一天的文档里写，同步时一边被覆盖（V1） | 可能丢失一边当天的速记，只能从文件历史找回 | 保持既定每日文档模型，不把单机验证当作双设备同步证明；复现丢失时按第 10 节处理 |
| 手机键盘和思源自己的键盘工具栏挡住输入面板（V2） | 核心体验受损 | 既有真机反馈与新增界面验证分开记录；本次新增入口仍需实际手机键盘与安全区核验 |
| 思源 App 或桌面端没有申请麦克风权限（V4） | 该客户端无法录音，插件无法补救 | 各端真机先录一段确认；拿不到麦克风的客户端只说明原因、不提供录音，不影响其他功能 |
| 腾讯云密钥明文存在插件设置里，随思源同步，同工作空间其他插件可读 | 密钥泄露后被盗用、产生费用 | 设置页提示只用语音识别权限的 CAM 子账号并设费用告警；密钥不进日志、提示、正文或 AI 材料 |
| 手机 WebView 直接请求腾讯云被跨域拦截 | 转写无法发出 | 实现前实测；被拦截则改由思源内核转发，仍是本机直连腾讯云 |
| 思源升级后插件 API 变了 | 入口或界面失效 | 只依赖 `petal` 公开的 API；内核接口只用常用的那几个 |
| 集市对收费的态度不明确 | 三期发布方式受影响 | 三期前去官方渠道确认 |
| AI 旧接口共用内核上下文 | 与其他插件同时调用可能混入材料或互相清理历史 | 沿用已接受风险；轻墨自身多入口不并发，调用结束再清理，见 6.6.3 |
| 新引用结构在轻墨编辑器往返时丢失 | 续写无法回到来源，或再次编辑破坏内容 | 先验证原生引用的保存、编辑与历史恢复，再交付入口；不放宽无关结构 |
