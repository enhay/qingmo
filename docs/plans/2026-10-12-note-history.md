# 单条笔记历史版本

## Need

用户编辑轻墨笔记后，可以按时间查看过去内容，恢复当前笔记或另存一条。复用思源原生文件历史，符合 [PRD](../轻墨-PRD.md) 的删除恢复与回收站边界；同一每日文档中的其他笔记不受恢复影响。

## Context

- 基线 f49e764，工作区干净。速记是每日文档内独立超级块，收录内容也可能是外部段落或整篇文档；原保存入口保留当前块 ID 和属性。
- 当前隔离思源已实际验证 createDocHistory、searchHistory(type=3,query=文档ID,op='')、getHistoryItems、getDocHistoryContent。历史内容返回带 data-node-id 的原生 DOM，可以按块 ID 提取。接口样本在本机临时验收目录。
- 原生快照粒度是文档，不能通过 rollbackDocHistory 恢复单条速记。原生生成、清理与同秒快照行为由思源决定，不承诺每次保存永久留档或跨设备完整历史。

## Scope

- In：卡片历史入口，版本时间列表、完整预览、恢复当前条目、另存新速记；编辑保存前留存原生历史。
- Out：逐字差异、独立版本数据库、独立回收站、永久保留、附件备份系统、同步系统改造、推送发布。

## Binding decisions

- D1：复用思源历史接口，按源文档查询、按当前块 ID 提取；相邻相同内容去重。分页按需读取，不把历史正文长期保存在插件存储。缺失块的快照不当作空版本恢复；读取失败与没有历史分开显示。
- D2：按用户截图采用宽面板：顶部居中标题与右上关闭，左侧时间倒序列表，选中后右侧展示原格式内容，预览底部提供操作；空列表显示暂无历史版本。窄屏允许时间列表与内容分步浏览，保留返回路径。保留期限沿用思源，不写死30天。
- D3：修改现有内容前先刷新事务并生成原生历史，生成失败不覆盖原笔记、保留草稿。恢复前同样保存当前版本，恢复作为一次新的修改，不消耗旧历史。未发送草稿不计版本；无内容变更不重复制造版本。
- D4：恢复只更新目标块，保留当前块 ID、位置及当前收录属性，历史正文标签与格式随内容恢复。不能调用整篇文档回滚来恢复一张卡片。只对既有安全可编辑的段落/超级块提供覆盖恢复，复杂结构与整篇文档引导思源处理。导致标签收录退出时沿用现有确认语义。旧子块身份不得与其他位置的块冲突。
- D5：另存走现有新建速记路径，生成新 ID，不修改来源笔记。图片仍引用现有资源，资源缺失需如实显示；历史预览继续安全过滤。原始历史身份与属性不作为新笔记身份复用。

## Delivery

1. 整体实现历史读取、保存前留存、历史面板和恢复/另存链路，保持同一模块单人所有权。
2. 在隔离思源中实际编辑产生历史，从卡片查看并恢复，再由API确认目标内容、原ID、邻居内容及收录属性；验证另存、空状态、读取失败和原生结构限制。按用户截图对照宽窄与亮暗界面。
3. 完成现有检查和必要的行为验证，本地提交，报告原生历史与设备验证边界。
