# 标签快速复用与所见即所得输入

## Need

按用户提供的 flomo 标签候选和格式工具栏截图升级轻墨输入体验：输入标签时能快速查找并复用历史标签，也能直接确认自己输入的新标签；文字和列表在输入时就显示最终格式，发送、草稿恢复及再次编辑后内容一致。对应 [PRD F2、F3](../轻墨-PRD.md)。

## Context

- 基线 `d8e653a`，主检出干净。现有输入是 textarea，格式按钮插入 Markdown 标记；历史标签来自当前收录集合的统计，目前仅按前缀匹配。
- 草稿契约是本机 localStorage 的正文与图片路径，未发送内容不写成思源块。新建和编辑按各自键保存，成功发送才清除。
- 已有保存逻辑保留块 ID 和属性；普通段落不允许变成多段或容器结构，避免思源单段落写回丢失后续内容。整篇文档及其他结构在思源中编辑。
- 宿主已提供 Lute。实际本机探针确认有 Markdown/HTML/BlockDOM 转换方法；下划线、高亮和原生标签的完整往返仍须在真实消费路径验证。不能只以 HTML 看起来正确作为保存成功的证据。

## Scope

- In：富文本输入、标签候选和键盘选择、格式工具栏、中文输入法、选区与撤销重做、本机草稿、保存与再次编辑的一致性、亮暗及宽窄界面验收。
- Out：AI、录音、导入、发布；不改变已有笔记的组织或收录语义，不把未发送草稿写成思源块，不扩大普通段落的结构编辑权限。

## Binding decisions

- D1：输入 `#` 后，以已输入文字匹配历史速记标签，支持名称中间的包含匹配与大小写不敏感匹配；候选沿用最近使用顺序，支持多级标签。暂不引入拼音、纠错或另一套标签存储。
- D2：点击候选，或上下键主动选中候选后按 Enter，复用该候选。没有主动选中候选时，Enter 确认 `#` 后已输入的完整标签名；同名复用，不自动补全成第一个相似标签。空标签不创建。Escape 关闭候选，中文输入法确认不触发标签提交；Enter 完成标签不发送笔记，Cmd/Ctrl+Enter 保留发送。
- D3：确认的标签有可识别的蓝色样式，继续输入回到普通正文。历史标签与新标签发送后都必须成为思源原生标签，能被现有统计和筛选读取；输入标签样式不代表提前持久化。
- D4：输入区域所见即所得。文字样式提供加粗、下划线、高亮，保留有序列表、无序列表和引用。按钮作用于当前选区或后续输入，反映当前格式，列表 Enter 连续创建下一项，空项 Enter 退出列表。保留原有宽度足够直接展开、窄屏收起的工具栏原则；图片继续沿用既有上传和预览流程。
- D5：优先使用宿主已有转换能力及原生浏览器编辑能力，不安装新依赖。富文本不是一份独立的远端笔记；持久化仍通过原有保存路径。格式、标签、链接、代码和附件必须在加载、编辑、草稿恢复、发送、再次编辑之间保真，不能静默丢弃原内容或块属性。无法安全编辑的原生结构交回思源，延续原有权限边界。
- D6：沿用现有安全渲染边界，粘贴的 HTML 不允许事件、脚本或危险 URL；不因富文本支持放宽权限。撤销重做、中文输入法及焦点切换不能丢字，旧纯文本草稿仍可恢复。

## Delivery

1. 把富文本输入、标签候选、工具栏与原保存路径作为同一编辑器模块实现；先证明真实格式和标签能往返保存，再完成界面整合。
2. 经实际界面输入并验证：名称中间匹配、主动选择历史标签、无候选选择时确认新标签、中文组合输入、格式与列表、草稿恢复；通过隔离思源 API/SQL 读回发送内容，再从卡片编辑验证。对照用户截图检查宽窄和亮暗界面。
3. 集成后运行既有检查与必要的行为验证，检查差异并本地提交；报告真机输入法及移动键盘等未覆盖范围，不推送。
