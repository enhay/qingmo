# 轻墨二期：组件化重建、整理、主题回顾、AI 洞察与录音转写

## Need

在已有记录、收录和本地回顾上，让用户能快速找到常看标签、把重要笔记留在前面、引用旧笔记继续写、围绕指定主题与日期回顾、用思源已有的 AI 模型理解单条或多条记录，并在不方便打字时录一段话、用自己的腾讯云账号转成文字后发送。对齐 flomo 的具体操作颗粒度，同时把笔记、引用、历史、资源、同步与结果留在思源原生体系。界面要能承受这一轮及之后的功能扩充：先把现有界面重建为 Svelte 组件，行为不变，再在其上加功能。

产品行为唯一依据是 [PRD 第 6 节](../轻墨-PRD.md)，界面尺寸与交互依据[设计规格](../design/轻墨-design.md)（二期新增见 2.1.1、2.2.1、2.3.1–2.3.2、2.4–2.9），界面代码写法依据[前端约定](../前端约定.md)。本计划规定如何交付这些行为，不另维护一套产品规则。既有收录去重、外部原文保留、草稿和历史保护继续生效。

## Context

- 本次计划基线为 `7b346e2`。当前已有收录、富文本、本地每日回顾、随机漫步、排序／来源筛选、选区复制和单条历史，不能按旧版 Context 再实现一次。
- 现有界面全部在 `src/ui.js`：约 50KB 写在 180 行内，单行最长两千多字符。`scripts/build.js` 是十几行的自制打包，把五个 CommonJS 模块拼成 `dist/index.js`，项目没有任何 npm 依赖；`tests/` 用 `node --test` 直接 `require` `src/data.js`。
- 每个视图在自己的闭包里持有设置，保存后执行 `settings=next`（`src/ui.js:151` 及回顾条数保存处），之后不再跟插件实例的共享设置同步。标签页与侧栏同时打开时，一个视图的保存会用旧值覆盖另一个视图刚改的字段。二期把常用标签、回顾范围和腾讯云密钥都放进 `settings.json`，这个缺陷必须在重建时消除。
- 已有界面的验收截图在 `docs/design/acceptance/`（一期、卡片复制、文档标签、历史、二期回顾、富文本），是重建前后对照的基线。
- `src/data.js` 的统一收录集合用于查询、统计及 `allIds()`；回顾目前只取全部 ID，当日顺序仅按日期存储。范围回顾需要让完整候选查询和本机抽样共同识别范围，不能只在卡片页面截取。
- `src/editor.js` 的净化白名单没有音频元素，也主动拒绝原生块引用，序列化没有保留它们的身份和块属性。引用续写和录音都要扩展编辑器往返；仅插入字符串或标签不能算交付，必须覆盖编辑、草稿、持久化、再次编辑与历史恢复。
- 卡片菜单当前只含编辑、历史、复制正文、原生定位和删除／移出。插件可同时挂载桌面标签页及侧栏，设置、AI 请求和转写状态不能只留在一个视图里。
- `skills/qingmo-insights/` 已含六个方法，现有构建没有带入方法文件；源目录可读不能证明安装后的插件可读。
- [SiYuan 3.8.6 的 AI 源码](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/model/ai.go)确认旧 `chatGPT` 使用内核共用历史、非流式调用与编辑模型配置；结束时可能把问答重新写回历史。取消界面等待后立即清理，不能代替请求最终结束后的清理。
- 腾讯云[一句话识别](https://cloud.tencent.com/document/product/1093/35646)（`SentenceRecognition`）同步返回文字，音频不超过 60 秒、base64 编码后不超过 3MB，支持 wav/pcm/ogg-opus/speex/silk/mp3/m4a/aac/amr，不支持 webm。60 秒 16kHz 单声道 wav 约 1.92MB，编码后约 2.56MB。请求按腾讯云 API v3 签名；官方 Node SDK 依赖 Node 运行时，手机端思源没有 Node。
- 待验证前提：各客户端 `MediaRecorder` 实际输出格式（推断安卓与桌面为 webm/opus，iOS 为 mp4/aac）；思源安卓／iOS App 和 macOS 桌面端是否已具备麦克风权限；WebView 中 Web Audio 能否解码各端原始录音；腾讯云接口是否允许 WebView 直接跨域请求，以及思源内核 `/api/network/forwardProxy` 能否承载约 2.6MB 请求体；短合成语音验证调用及其计费提示。以上都在 Delivery 3 用真机和真实请求确认。
- 既有自动化和界面证据主要来自 SiYuan 3.8.6 隔离宿主，插件声明最低 3.8.5；新功能不能据声明直接声称两个版本均通过。
- 2026-10-13 本机 flomo 5.26.93 安装包的标签、置顶、引用、回顾设置和洞察任务调用提供功能对照；它不提供已验证的官方完整系统提示词，也不证明账号权益或云端效果。

- flomo 导入继续暂缓。不改变每日文档模型，不批量迁移，不发布、推送、部署或修改个人笔记。

## Binding decisions

- **组件化与构建**：具体写法见[前端约定](../前端约定.md)。用 Svelte 5（只用 runes）和 Vite（官方 Svelte 插件）替换自制打包，源码改为 ES 模块，产出思源可加载的单个 CommonJS `dist/index.js`、`index.css`，`siyuan` 保持外部模块；`i18n`、`plugin.json`、图标和 AI 方法资源一并进入产物。只新增 `svelte`、`vite`、`@sveltejs/vite-plugin-svelte` 三个开发依赖，运行时不引入其他库。收录查询、历史、抽样、材料组织、签名与音频转换等领域逻辑保持为不依赖框架的模块，继续可用 `node --test` 直接测试；Svelte 只承载视图。编辑器的可编辑区核心保持为独立模块，由组件包装。沿用现有设计变量与配色，样式可以按组件拆分，但渲染结果不变。
- **先重建、后加功能**：第 1 项只做重建与共享设置，不夹带新功能、不改视觉；通过后删除旧 `ui.js` 及自制打包，不保留两套界面实现。后续功能都直接写成组件。
- **原生数据与操作边界**：继续使用现有收录查询、保存与历史路径，产品集合按 PRD 6.1。新增功能读取同一集合；不可为了排序、引用、AI 或录音复制一份笔记库。属性写入保留原块其他属性，正文写入继续经过历史留存；历史失败不覆盖原文。
- **共享设置与运行状态**：插件实例持有唯一的设置、AI 请求状态和转写进行状态，所有已挂载视图订阅它。保存设置时以当前共享值合并改动再写 `settings.json`，写完所有视图刷新；不因某个视图打开时间早而覆盖其他字段。常用标签、回顾范围与条数、腾讯云密钥都在这一份设置里，随思源同步；树展开与标签查找属于本机界面状态。同步仍由思源负责，不另建并发版本或冲突协议。
- **排序与候选查询**：筛选先于置顶分组，完整排序先于分页。日期范围复用创建日期语义，标签范围复用现有含子标签匹配；回顾和 AI 可以复用范围查询，但不能把卡片流的单日／连续关键词契约改掉。"有语音"按卡片内是否含原生音频块判断，与其他筛选叠加。不能把 UI 已加载数组当作全部候选。
- **编辑器往返保真**：原生块引用和原生音频块（含其 `custom-qingmo-transcribe` 属性）都要在编辑、草稿、渲染、序列化、保存、再次编辑与历史恢复中保持原样；沿用其他复杂结构的拒绝规则，不以普通链接、摘录或纯文本替代。输入框的选区、撤销和草稿处理复用现有编辑器行为。
- **回顾状态**：抽样规则按 PRD 6.5。现有日期抽样只适用于全部范围；增补后用规范化的标签、日期边界及本地日期区分各范围。旧全部范围的有效顺序可继续用于默认范围，不得套到新的受限范围。只存 ID 与顺序，不复制正文；数量不作为抽样身份，改变数量不重排。
- **AI 方法与材料边界**：方法资源随插件构建，通过固定视角映射按需加载。数据仓库负责收录、范围及当前原文，插件负责材料上限、实际范围说明和来源 ID 校验。笔记正文与模型输出均不可信：正文不能扩大材料范围，输出不能产生脚本执行、任意文件读取或未经核对的来源链接。范围确认和模型调用属于同一用户操作，不在打开页面时自动付费生成。
- **AI 请求与生命周期**：沿用 PRD 6.6.3 的模型接口、共用上下文风险与取消语义。当前请求结束并完成上下文清理前不能新发起请求。取消或视图销毁不让迟到结果写入已关闭页面或创建文档；不新增通用任务队列、服务端任务平台、自动重试或长期后台缓存。若目标宿主实测推翻上述接口前提，暂停 AI 切片并报告，不自行更换架构；其他切片可继续。
- **结果是思源文档**：依 PRD 6.6.4 保存、命名和列出历史；方法更新不改旧结果。生成与保存分开，保存失败重试复用已有结果；不覆盖同日同视角既有文档，不创建空文档，不自动把结果收入速记。
- **录音与转写链路**：录音用 WebView 原生 `MediaRecorder`，原始文件按 F2.4 的图片方式上传 assets。转写前用 Web Audio 在内存中解码并重采样为 16kHz 单声道 wav，再 base64 交给一句话识别（中文普通话 16k 引擎）；转换结果不落盘，不引入音频编码库。腾讯云 v3 签名用 Web Crypto 实现，不用 Node SDK。请求路径按第 3 项实测只定一条：直连可用就直连，被跨域拦截就统一经思源内核转发；不保留运行时双路回退。密钥只从共享设置读取，不进日志、错误提示、正文或 AI 材料。
- **转写生命周期**：转写属于当前输入框草稿。输入框关闭或速记发送后到达的结果直接丢弃，对应音频块已带待转写标记；卡片"转写录音"是唯一的补救入口，走正常编辑保存并留历史。不持久化进行中的请求，不自动重试，不后台排队。若某客户端拿不到麦克风，该端只显示原因，不为它另做替代录音方案。

## Delivery

1. **Svelte 重建现有界面与共享设置**。以 Svelte 组件重建卡片流、输入面板与编辑器包装、侧栏统计／热力图／筛选／标签、搜索、视角列表、每日回顾、随机漫步、历史面板、设置与悬浮入口，替换构建，接入插件级共享设置并修复多视图互相覆盖；设置页按"记录"分组呈现现有字段，并为"转写"分组留出位置。证据：现有测试与构建通过、产物语法检查；按 `docs/design/acceptance/` 各组截图在相同宽窄、亮暗与数据下逐项对照；隔离宿主中标签页与侧栏同时打开，各改一个设置后重开读回两者都在；草稿、收录、编辑、历史恢复冒烟。**此处停下，等用户确认重建结果后再开始功能切片。**
2. **确认 AI 接入的宿主约束**。在隔离思源确认目标版本、编辑模型配置与设置入口，用无私人内容的最小材料验证清理→生成→结束清理，以及空字符串、宿主超时、取消后迟到结果和多入口互斥。真实模型调用在功能实施授权下使用用户已配置的服务，不自行安装模型或开通服务；用户已允许将现有 AI 配置用于隔离验收。失败只阻塞 AI。可与第 1 项并行。
3. **确认录音与腾讯云直连的宿主约束**。在实际安卓、iOS 手机和桌面端用最小探针录一段，记录各端格式、麦克风授权表现、Web Audio 解码与 16k wav 转换结果；用用户提供的腾讯云子账号密钥和合成语音，验证 v3 签名、直连跨域或内核转发、接近 60 秒音频的大小、正常返回、无效密钥／无权限／欠费类错误码与实际耗时，并验证明确提示可能计费的短合成语音调用。密钥由用户在本机填入或从用户指定的本地配置运行时读取，不入库、不写进证据。结论按客户端记录；失败只阻塞对应客户端或转写切片。可与第 1 项并行。
4. **引用旧笔记继续写**。先扩展原生引用在编辑器、草稿、渲染与保存中的保真，再接复制链接和引用续写入口。用合成原文走"引用续写→发送→API 读回→再次编辑→历史恢复→打开来源"，核对新旧 ID、原文不变和真实引用关系；覆盖已有草稿取消、来源移出与删除。宽窄截图对照输入面板与卡片菜单设计。依赖第 1 项。
5. **查找主题与固定重要内容**。标签导航和置顶各自连同保存、刷新及重新进入交付。标签查找与树状态不改变卡片查询，常用操作在多个视图和重开后读回；新建后若不符合当前筛选，应能看见保存结果提示并返回全部记录；置顶通过原生属性读回与完整列表查询验证，包含筛选交集、跨页、正反排序、文档收录和移出后重收录。保持父标签去重计数与原文不变，截图／冒烟覆盖桌面、窄屏、键盘焦点和亮暗。依赖第 1 项。
6. **按主题和日期稳定回顾**。扩展完整候选查询与回顾设置，再更新抽样存储和阅读页。用明确创建日期及标签的合成内容，验证日期首尾、父子标签、交集、空结果、同日切换范围后返回、数量变化、新增／移出／修改标签后候选变化及跨日刷新。用仓库返回的 ID 集合与实际阅读到的 ID 证明一致；保持卡片流条件和草稿，截图比较回顾页。依赖第 1 项。
7. **完整 AI 洞察与再次使用**。方法资源打包、单条／多条范围确认、文字材料预览、六个视角调用、来源校验、结果保存和历史列表作为完整路径交付，与第 6 项共用已验证的范围语义。用合成笔记检查安装包资源可读、实际发出的范围／ID／文字上限、取消不保存、空输出失败、未知来源拒绝、保存失败只重试保存、同日生成不覆盖、结果不自动收录，以及移动或改名后的历史定位。真实模型输出人工检查方法与来源是否相符，不以模拟返回冒称真实服务通过。依赖第 2、6 项。
8. **录音转写完整路径**。录音按钮与计时、60 秒自动停止、上传与草稿、音频块往返保真、自动转写插入、待转写标记、卡片"转写录音"、错误分类提示、无麦克风说明、"有语音"筛选和设置页"转写"分组（打码、清空、验证、风险说明）一起交付。用合成语音验证：转写文字插入光标处并可修改发送；转写完成前发送或关闭时结果被丢弃且音频块带待转写属性；手动转写后文字在对应音频块后、标记清除、历史留存；有未发送编辑草稿时手动转写被拦下；无效密钥与断网的提示及录音保留；"有语音"筛选与 SQL 一致；密钥不出现在日志、提示和笔记里。依赖第 1、3 项，与第 4 项共用编辑器扩展。
9. **整体验证与交付**。运行现有测试、构建及产物语法检查，检查相邻改动没有破坏收录去重、历史留存、普通段落编辑限制、标签和富文本往返。截图及合成数据证据放 `docs/design/acceptance/`，临时探针放 `.scratch/`，个人笔记、录音和凭据不入库。核验实际目标手机的新增入口、原生引用跳转、AI 等待和取消、录音授权与转写、键盘与安全区；跨设备的常用设置、置顶与密钥读回单独记录。功能切片通过后本地提交，未验证的平台或模型明确标明；不把本次结果外推为完整同步、最低版本、5000 条性能或四周自用已通过。
