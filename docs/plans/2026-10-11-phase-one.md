# 轻墨一期本地实现计划

## Need

按 [PRD 的一期 F1–F7](../轻墨-PRD.md) 和 [设计规格](../design/轻墨-design.md)，让用户在思源内打开即记，发送后从卡片流回看、编辑、搜索和筛选；每条速记始终是可在思源编辑器使用的原生超级块。此次交付可构建的本地插件与验证证据，安装自用前完成真机验收。

## Context

- 当前目录只有产品文档和参考截图，无代码、依赖清单或 Git 仓库。保留全部原始资料。
- 本机安装思源 3.8.5，内核提供独立工作空间运行能力；本地验证使用项目 `.scratch/` 下的隔离工作空间，不接触个人笔记。
- 手机没有 `addTab`，全屏层使用 DOM；桌面使用 `addDock`，两者共用界面。接入签名以公开 petal 类型与本机宿主为准。
- 原文要求开工前完成 V1–V3。本次范围已调整为先本地实施，V1 双设备同步、V2 真机键盘、V3 冷启动及杀进程草稿恢复留作安装自用前验收。本地浏览器与单内核结果不能替代这些证据。

## Scope

- In：入口与退出、文字及图片输入、标签候选与基本 Markdown 格式、本机草稿、分页卡片、编辑复制删除及思源定位、统计与热力图、层级标签、关键词组合筛选、设置、桌面侧栏与快捷键、亮暗主题及无障碍。
- Out：录音转写、AI、每日回顾、随机漫步、flomo 导入、授权付费、上架；不同步草稿，不自行清理 assets，不引入冲突合并或设备分文档；不安装到用户工作空间、不发布。

## Binding decisions

- D1：沿用已定模型：随机文档 ID，每日文档 `custom-qingmo-day`，超级块 `custom-qingmo-memo="1"`，时间读 `created`。按发送时本地日期查当日属性，再查所选笔记本中的模板路径，最后创建。当天已标记文档仍复用，设置变化只影响后续新建文档。编辑保留原块 ID 与标记。
- D2：数据检索以标记超级块为单位去重，覆盖全部子段落；关键词与标签及图片/链接/无标签/日期条件组合。每页 20 条，按创建时间及 ID 倒序稳定排序。标签树父级统计包含子标签且每条速记只计一次；最近标签按最后使用日期排序。天数用本地日历日期差，热力图按周日开始的最近 12 个日历周展示至今天，未来日期不可筛选。
- D3：草稿键、300ms 防抖及存储失败处理遵循 PRD；关闭面板、切后台及卸载前补写未落盘草稿。上传成功的图片进入草稿，发送失败不清空。保存期间禁用重复提交，成功写入与列表刷新分开处理，刷新失败不重发已保存内容。
- D4：使用普通 JavaScript、DOM、CSS 和宿主公开 API；Node 标准库负责构建及测试，不新增或安装 npm 依赖。源码采用 CommonJS 模块，构建为宿主加载的单个 `index.js`；宿主提供 `siyuan`。所有用户文案在 `i18n/zh_CN.json`，英文暂沿用中文。
- D5：全屏按设计尺寸与颜色，侧栏与悬浮入口使用宿主变量；一期隐藏麦克风。键盘定位使用 visualViewport 和宿主键盘事件；移动返回优先退出输入/子面板，再退出轻墨。所有按钮支持键盘与 aria，44px 触控，减少动态效果。HTML/URL 均在渲染信任边界校验，记录内容不能成为脚本执行入口。
- D6：模块边界：`src/data.js` 提供 `MemoRepository`、Markdown/标签与日期纯函数及 `DraftStore`；`src/ui.js` 和 `src/styles.css` 提供共用视图；`src/index.js` 提供 Plugin 生命周期和宿主桥接。并行工作只编辑各自模块，整合后统一验证。

## Delivery

1. **原生数据与本机草稿**：从输入 Markdown 到每日文档和超级块，读回整条内容，编辑保持 ID、删除仅删除指定块；搜索第二段、分页、标签和统计都消费同一批标记块。通过隔离思源内核直接写入、读取及查询验证，纯函数用 Node 测试验证标签、日期、草稿及边界。
2. **完整共用界面**：按参考图完成卡片流、侧边栏、输入、图片、设置和搜索，使发送、编辑、删除和筛选连接数据层。观察真实页面与内核共同运行的消费路径；以 402×874 浏览器截图对照参考图，保留截图与差异说明。真机 ±1pt 叠图结论留待设备验收。
3. **宿主与本地交付**：接入主菜单、移动悬浮按钮、桌面侧栏/快捷键、启动设置、主题、同步和前台刷新，卸载清理订阅与 DOM；构建本地插件包。验证包能在隔离宿主加载，记录 3.8.5 实测范围和设备限制。
4. **整体验证**：本地真实内核验证新建→显示→编辑→组合搜索→删除，图片上传/读取，失败保留草稿；用合成数据观察 5000 条首屏与统计耗时。运行相关自动检查，阅读全部新增代码，记录未通过与未验证项。V1–V3 及连续四周自用不能用本次本地检查宣称通过。

## Status

一期本地实现已完成。Delivery 1 的原生数据与草稿、Delivery 2 的共用界面、Delivery 3 的隔离宿主接入与本地包、Delivery 4 的本地检查均已接受，证据见 [一期本地验收](../design/acceptance/一期本地验收.md)。5000 条合成速记的桌面页面刷新至绘制约 691ms、完整统计约 243ms；6 项回归测试通过。未安装到个人工作空间、未发布；目录原本不是 Git 仓库，因此无本地提交。安装自用仍待 V1–V3、真机视觉与性能验收，当前不等待额外架构决策；若 V1 失败，数据模型调整需另行确认。

官网帮助对照后的本地细节完善已完成，范围见 [参考与交互细节](../design/flomo参考与交互细节.md)。本次仅构建、语法与代码检查，按用户要求不新增或运行测试；以上宿主、截图和性能证据来自原一期验收，本次界面改动尚未做渲染与真机复核。AI Skill 已补充单条／多条解读及引用细节，仍未接入一期插件。
