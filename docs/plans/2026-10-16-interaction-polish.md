# 轻墨三轮：交互细节对齐 flomo

## Need

记录、收录、回顾、AI 洞察和录音转写的主流程已经具备，日常用起来还在细节上输给 flomo：桌面上粘贴截图没有反应，常用操作没有快捷键，单条笔记想得到 AI 回应要先打开菜单，看引用要跳到思源，被谁引用看不到，回看图片、统计和随机漫步时都缺少顺手的入口。本轮按 flomo 的操作颗粒度补齐这些细节，让用户在轻墨里就能记得更快、回看时不离开轻墨。笔记仍是思源原生块，收录方式、每日文档和块属性模型不变。

产品行为唯一依据是 [PRD 6.9](../轻墨-PRD.md)，界面规格是[设计规格 2.10](../design/轻墨-design.md)，界面代码写法依据[前端约定](../前端约定.md)。本计划只规定怎么交付，不另维护一套产品规则。

## Context

- 本计划基线为 `fc0b196`。现有界面是 Svelte 5 组件（`src/views/`、`src/components/`），领域逻辑在 `src/core/`，测试用 `node --test` 跑 `tests/`。
- 输入框粘贴在 `src/editor/editor.js:47` 处理：只读剪贴板的 `text/html` 和 `text/plain`，图片文件被静默丢弃；没有拖放处理。「添加图片」按钮已有上传和缩略图流程，粘贴和拖入应接到同一流程。
- 视图内键盘处理只有 `src/views/App.svelte:59` 的 Esc、Tab 和 `src/views/Composer.svelte:51` 的 ⌘/Ctrl+Enter 发送；插件只注册了全局 ⌥⇧Q。⌘B、⌘U 目前可能由浏览器的可编辑区默认处理，其产物是否与 Aa 按钮相同、能否经过编辑器净化和序列化往返，尚未验证。高亮在编辑器里是带背景色的 `span`（`decorate`），不是 `<mark>`。
- Shift+Enter 在编辑器里是软换行（`cbd7e37` 修复过软换行保真），所以不照搬 flomo 的 Shift+Enter 发送。
- 思源自身也监听全局按键。待验证：轻墨标签页内按 ⌘K、⌘B、⌘U、⌘⇧H、方向键时，思源是否同时响应，`stopPropagation` 能否拦住。拦不住的组合按 PRD 6.9 放弃并在验收里写明。
- 卡片在 `src/components/MemoCard.svelte`：头部只有时间和「⋯」；点击正文里的 `siyuan://blocks/` 链接直接 `openBlock` 跳到思源（第 15 行）。卡片同时用于卡片流和回顾页（`review` 属性）。卡片菜单的「AI 洞察」在 `App.svelte:90` 一带，悬停入口复用同一处理。
- 编辑草稿按 `qingmo:draft:<块ID>` 存在本机 `localStorage`，读写在 `src/core/data.js:124-136`。插件可以同时挂载标签页和侧栏，草稿标记要在所有已挂载视图中一致。
- 大图层由 `App.svelte:46` 的 `image(url)` 打开，只接收一个地址。
- `repository.list()`（`src/core/data.js:204`）已支持单日筛选 `day=yyyyMMdd` 与 `kind='image'`；「去年今日」和宫格都在现有查询上实现。`stats()`（`data.js:285`）用 SQL 聚合热力图，统计页同样要在 SQL 里按日、按月 `GROUP BY` 完整集合，不能拉取明细行再在前端累加。
- 引用续写已打通原生块引用在编辑器、草稿、保存、再次编辑和历史恢复中的往返（二期 Delivery 4），`@` 插入复用同一份序列化。
- 待验证：思源 `refs` 表在目标宿主（3.8.6／3.8.7）的列名与语义（被引块、引用方块、所在文档），以及引用方是子块时能否用现有 `descendants`／`MEMOS` 结构映射回卡片。`blocks.content` 对容器块是否重复包含子块文字也待确认；字数只能按叶子块累加，避免重复计数。
- flomo 对照材料：桌面版样式与模板在 `.scratch/flomo-5.26.93/`，帮助中心配图在 `.scratch/flomo-help/`（按功能命名，webp 已转 png 的在 `png/` 子目录）。两者都不入库。
- 既有验证方式：隔离工作空间、合成数据、`.scratch/` 里的临时探针，验收文档放 `docs/design/acceptance/<主题>/`。

## Scope

- In：PRD 6.9 全部条目，包括粘贴和拖入图片、双击编辑、草稿标记、视图内快捷键、`@` 快速引用、悬停洞察入口、引用预览与悬停浮层、被引用次数与引用面板、去年今日、图片宫格、多图查看、随机漫步回看、历史版本相对时间与字数、统计页、长笔记折叠设置，以及这些路径需要的中文文案、无障碍、宽窄屏和亮暗主题。
- Out：PRD 6.9 末尾列出的不做项（⌘\ 收起侧栏、Shift+Enter 发送、手机左滑、多关键词和关键词高亮、标签 emoji、分享图、扩展统计图表、漫步明信片与关联游走、引用面板内编辑与多层导航）。另外不做：给引用关系、字数或统计建缓存表或新块属性；为卡片流以外的筛选做宫格；修改思源键位或注册新的全局命令；英文文案；迁移、推送、发布。

## Binding decisions

- D1 **只读思源已有数据**：被引用次数和引用面板直接查询思源的 `refs` 与块表，作为 `src/core/data.js` 仓库的新方法；不写属性，不建关系表，不缓存。次数按当前页卡片批量查询，一页一次，不能每张卡片各发一次请求。
- D2 **引用面板是一个组件**：新建一个只读面板组件，放进现有 `Dialog` 弹层（手机底部升起、桌面居中），承载「引用的笔记」和「被引用列表」两种内容，只有一层，替换式切换。轻墨集合里的目标用 `MemoCard` 只读形态渲染（不带菜单）；非集合块用现有 `renderBlockDOM` 渲染，并经过同样的安全过滤。桌面悬停浮层是同一份只读渲染的轻量形态。
- D3 **`@` 候选复用标签候选**：触发、方向键、Esc、输入法组字判断沿用 `Composer.svelte` 的 `#` 候选机制；候选数据用 `repository.list({keyword, order:'newest'})`，不新写搜索语义；插入复用引用续写的原生引用节点。
- D4 **图片输入只有一条上传路径**：粘贴和拖入的图片文件交给「添加图片」的同一上传函数，草稿、缩略图、失败提示与 F2.4 相同；正文不出现图片节点。
- D5 **宫格是卡片流的一种渲染**：`kind==='image'` 时同一份查询结果、同一分页，换成宫格组件渲染；格子复用卡片菜单处理。大图层改为接收「图片列表＋起始序号」，卡片和宫格共用。
- D6 **统计页**：仓库新增一个统计方法，按月或按年在 SQL 里一次聚合出指标与逐日、逐月条数；统计页是主栏的新视图，进入、返回方式与回顾页相同；侧栏统计数字改为按钮。字数按 PRD 6.9 的口径：前端在 `src/core/` 放一个字数函数供历史版本使用，SQL 端按同一定义（去掉空白、只算叶子块）实现，两边口径一致。
- D7 **偏好与运行状态**：「长笔记折叠」是 `DEFAULT_SETTINGS` 的新字段，走插件级共享设置，所有视图订阅；草稿标记由插件实例的共享状态驱动，输入框写入或清除草稿时通知，不轮询 `localStorage`；随机漫步的已看记录是 `Review.svelte` 的组件内状态，不持久化。
- D8 **快捷键只在轻墨内生效**：都在轻墨根节点的按键处理里实现，被消费的按键阻止冒泡；焦点不在轻墨内时不响应；不用 `addCommand` 注册这些键。悬停洞察入口用 `@media (hover:hover)` 加 `:hover`／`:focus-within` 控制显示，点击调用卡片菜单「AI 洞察」的同一处理。
- D9 **测试**：最多新增两条测试，放在 `tests/data.test.js`：被引用计数的去重规则（子块引用归入卡片、同一引用方块只计一次、排除自引用），以及统计页聚合（逐日条数、记录天数、单日最多）。其余行为用一次性脚本或隔离宿主冒烟验证，不进仓库。

## Delivery

1. **输入框效率**：粘贴与拖入图片、⌘B／⌘U／⌘⇧H 格式快捷键、`@` 快速引用。验证剪贴板只有图片、图文混合、拖入多张、拖入非图片文件；快捷键产物经保存再编辑与 Aa 按钮一致；`@` 插入的引用发送后由 API 读回为原生引用，再次编辑和历史恢复不丢。归属 `Composer.svelte`、`src/editor/`。
2. **卡片头部与偏好**：悬停洞察入口、草稿标记、桌面双击编辑、长笔记折叠设置。验证悬停入口进入单条范围确认且没有发出模型请求；标签页与侧栏同时打开时草稿标记一致；双击链接、标签、引用、图片、音频不进入编辑；关闭折叠后重开设置读回。归属 `MemoCard.svelte`、`Settings.svelte`、共享设置。
3. **引用预览与被引用次数**：仓库查询、引用面板、悬停浮层、卡片底部次数。先在隔离宿主确认 `refs` 前提，再接界面。用合成数据覆盖：子块被引、同一块多次引用、卡片内自引用、非轻墨文档引用、被引目标已删除、整篇收录卡片。依赖第 2 项（同改 `MemoCard.svelte`）。
4. **浏览**：去年今日、图片宫格、多图查看、⌘K 聚焦搜索。验证 2 月 29 日映射、宫格与其他筛选叠加、置顶分组和翻页、查看器序号与左右切换。
5. **回顾与历史**：回顾页 ←／→、随机漫步回看、历史版本相对时间与字数（含 `src/core/` 字数函数）。验证跨午夜的「今天／昨天」边界，以及回看后再前进不重新抽样。
6. **统计页**：仓库统计方法、统计视图、侧栏入口。依赖第 5 项的字数口径。用已知创建日期和文字的合成数据核对月、年各指标，以及点日期回到卡片流单日筛选；5000 条合成数据下统计查询在 300ms 内返回（沿用 PRD 第 8 节热力图的性能线）。
7. **整体验证**：运行现有测试、构建和产物语法检查；检查收录去重、草稿、历史留存、标签与富文本往返没有被破坏；证据放 `docs/design/acceptance/interaction-polish/`。

第 3、4、6 项都要改 `App.svelte`，不要并行修改同一份文件；其余切片可以并行。每个切片完成后单独本地提交，并在下面的 Status 记录接受或阻塞情况。视觉效果由用户验收，执行方不自行截图对照，除非用户另行要求。
