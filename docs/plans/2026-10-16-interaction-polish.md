# 轻墨三轮：交互细节对齐 flomo

## Need

记录、收录、回顾、AI 洞察和录音转写的主流程已经具备，日常用起来还在细节上输给 flomo：桌面上粘贴截图没有反应，常用操作没有快捷键，单条笔记想得到 AI 回应要先打开菜单，在卡片上看不到被谁引用，桌面上看一眼被引内容也得跳到思源，回看图片、统计和随机漫步时都缺少顺手的入口。本轮按 flomo 的操作颗粒度补齐这些细节，让用户在轻墨里就能记得更快、回看时少离开轻墨。引用的搜索、预览和反向引用优先用思源原生能力，不在轻墨里另造一套。笔记仍是思源原生块，收录方式、每日文档和块属性模型不变。

产品行为唯一依据是 [PRD 6.9](../轻墨-PRD.md)，界面规格是[设计规格 2.10](../design/轻墨-design.md)，界面代码写法依据[前端约定](../前端约定.md)。本计划只规定怎么交付，不另维护一套产品规则。

- 待验证：`blocks.content` 对容器块是否重复包含子块文字；字数只能按叶子块累加，避免重复计数。

- 既有验证方式：隔离工作空间、合成数据、`.scratch/` 里的临时探针，验收文档放 `docs/design/acceptance/<主题>/`。

## Scope

- In：PRD 6.9 全部条目，包括粘贴和拖入图片、双击编辑、草稿标记、视图内快捷键、`@` 快速引用（思源引用搜索）、悬停洞察入口、桌面悬停引用弹出思源浮窗、被引用次数、去年今日、图片宫格、多图查看、随机漫步回看、历史版本相对时间与字数、统计页、长笔记折叠设置，以及这些路径需要的中文文案、无障碍、宽窄屏和亮暗主题。
- Out：PRD 6.9 末尾列出的不做项（⌘\ 收起侧栏、Shift+Enter 发送、手机左滑、多关键词和关键词高亮、标签 emoji、分享图、扩展统计图表、漫步明信片与关联游走、轻墨自建引用面板或预览浮层与自定计数口径、手机端轻墨内预览、`((` 触发、把输入框换成思源编辑器）。另外不做：给引用关系、字数或统计建缓存表或新块属性；为卡片流以外的筛选做宫格；修改思源键位或注册新的全局命令；英文文案；迁移、推送、发布。

## Binding decisions

- D1 **引用界面交给思源**：桌面悬停引用和点击「被引用 N 次」都调用 `addFloatLayer`，浮窗内容、编辑与跳转全部是思源行为，轻墨不写引用面板、预览浮层或自己的引用渲染；点击引用沿用现有 `openBlock`；手机端一律打开思源原文。被引用次数的口径就是思源编辑器显示的引用计数，取自思源已有数据，按当前页卡片批量读取，一页最多一次请求；不写属性、不建表、不缓存，也不另定去重规则。浮窗触发遵循思源的浮窗设置。
- D3 **`@` 候选**：触发、方向键、Esc、输入法组字判断沿用 `Composer.svelte` 的 `#` 候选机制。两路数据都经 `src/core/` 仓库方法取得，组件不直接请求内核：轻墨段用现有 `repository.list({ keyword, order: 'newest' })`，不另写匹配；思源段用 `/api/search/searchRefBlock`，不改它的排序。合并时按块归属把思源结果映射回轻墨卡片（卡片本身或其子块）并去重，用一次批量查询判断归属，不能逐条请求。轻墨候选调用引用续写同一个 `editor.insertReference(卡片ID, 正文开头)`；思源候选用同一方法传命中块 ID 与思源返回的锚文本。两路请求按输入防抖，迟到的旧关键词结果丢弃。
- D4 **图片输入只有一条上传路径**：粘贴和拖入的图片文件交给「添加图片」的同一上传函数，草稿、缩略图、失败提示与 F2.4 相同；正文不出现图片节点。
- D5 **宫格是卡片流的一种渲染**：`kind==='image'` 时同一份查询结果、同一分页，换成宫格组件渲染；格子复用卡片菜单处理。大图层改为接收「图片列表＋起始序号」，卡片和宫格共用。
- D6 **统计页**：仓库新增一个统计方法，按月或按年在 SQL 里一次聚合出指标与逐日、逐月条数；统计页是主栏的新视图，进入、返回方式与回顾页相同；侧栏统计数字改为按钮。字数按 PRD 6.9 的口径：前端在 `src/core/` 放一个字数函数供历史版本使用，SQL 端按同一定义（去掉空白、只算叶子块）实现，两边口径一致。
- D7 **偏好与运行状态**：「长笔记折叠」是 `DEFAULT_SETTINGS` 的新字段，走插件级共享设置，所有视图订阅；草稿标记由插件实例的共享状态驱动，输入框写入或清除草稿时通知，不轮询 `localStorage`；随机漫步的已看记录是 `Review.svelte` 的组件内状态，不持久化。
- D8 **快捷键只在轻墨内生效**：都在轻墨根节点的按键处理里实现，被消费的按键阻止冒泡；焦点不在轻墨内时不响应；不用 `addCommand` 注册这些键。悬停洞察入口用 `@media (hover:hover)` 加 `:hover`／`:focus-within` 控制显示，点击调用卡片菜单「AI 洞察」的同一处理。
- D10 **格式由工具执行**：用 Prettier 与 `prettier-plugin-svelte`（精确版本锁定）格式化 `src/`、`tests/`、`scripts/` 和根目录配置脚本，不格式化 Markdown 文档；`npm run format:check` 与测试、构建一起作为每个切片的提交前检查。格式化提交只改格式，行为不变的证据是格式化前后构建产物一致，或差异只在空白与注释。
- D9 **测试**：最多新增一条测试，放在 `tests/data.test.js`，覆盖统计页聚合（逐日条数、记录天数、单日最多）。引用相关口径归思源，不为它写测试。其余行为用一次性脚本或隔离宿主冒烟验证，不进仓库。

## Delivery

0. **格式化与约定修正**：加入格式化工具与命令，单独一次纯格式化提交；`前端约定` 按现状改写样式位置的规则，并写入格式检查要求；把散落各处的「轻墨」标签名收成 `src/core/` 的一个常量。这一项在所有切片分派前完成，其余切片都基于它。
1. **输入框效率**：粘贴与拖入图片、⌘B／⌘U／⌘⇧H 格式快捷键、`@` 快速引用。验证剪贴板只有图片、图文混合、拖入多张、拖入非图片文件；快捷键产物经保存再编辑与 Aa 按钮一致；`@` 候选先列轻墨笔记、再列思源结果，命中卡片内段落时引用落在卡片上且只出现一次，快速输入时不出现旧关键词的结果，`a@b` 不触发，插入的引用发送后由 API 读回为原生引用，再次编辑和历史恢复不丢。归属 `Composer.svelte`、`src/editor/`。
2. **卡片头部与偏好**：悬停洞察入口、草稿标记、桌面双击编辑、长笔记折叠设置。验证悬停入口进入单条范围确认且没有发出模型请求；标签页与侧栏同时打开时草稿标记一致；双击链接、标签、引用、图片、音频不进入编辑；关闭折叠后重开设置读回。归属 `MemoCard.svelte`、`Settings.svelte`、共享设置。
3. **思源浮窗与被引用次数**：先在隔离宿主确认 Context 列出的浮窗与计数前提，再接卡片：桌面悬停引用弹出思源浮窗，卡片底部显示被引用次数，点击后桌面弹出引用方浮窗、手机打开原文。用合成数据覆盖：子块被引、同一块多处引用、非轻墨文档引用、被引目标已删除、整篇收录卡片，逐项核对卡片上的次数与思源编辑器显示一致。浮窗如果无法列出引用方，点击改为打开原文并报告，不自建列表。依赖第 2 项（同改 `MemoCard.svelte`）。
4. **浏览**：去年今日、图片宫格、多图查看、⌘K 聚焦搜索。验证 2 月 29 日映射、宫格与其他筛选叠加、置顶分组和翻页、查看器序号与左右切换。
5. **回顾与历史**：回顾页 ←／→、随机漫步回看、历史版本相对时间与字数（含 `src/core/` 字数函数）。验证跨午夜的「今天／昨天」边界，以及回看后再前进不重新抽样。
6. **统计页**：仓库统计方法、统计视图、侧栏入口。依赖第 5 项的字数口径。用已知创建日期和文字的合成数据核对月、年各指标，以及点日期回到卡片流单日筛选；5000 条合成数据下统计查询在 300ms 内返回（沿用 PRD 第 8 节热力图的性能线）。
7. **整体验证**：运行现有测试、构建和产物语法检查；检查收录去重、草稿、历史留存、标签与富文本往返没有被破坏；证据放 `docs/design/acceptance/interaction-polish/`。

第 4、6 项都要改 `App.svelte`，不要并行；第 3 项要等第 2 项，第 6 项要等第 5 项；其余切片可以并行。每个切片完成后单独本地提交，并在下面的 Status 记录接受或阻塞情况。视觉效果由用户验收，执行方不自行截图对照，除非用户另行要求。
