# flomo 参考与轻墨交互细节

参考日期：2026-10-11。以 flomo 官方帮助中的实际说明为依据，对照轻墨现有 PRD、设计和一期代码。官网包含后续版本能力，不能用它覆盖已经确认的一期范围。

## 记录、编辑和查找

| 官方参考 | 轻墨中的处理 |
|---|---|
| [快速记录](https://help.flomoapp.com/basic/quick-input.html)：降低输入负担，提供发送和格式快捷操作 | 保留无标题输入、Enter 换行和 Cmd/Ctrl+Enter 发送。中文输入法选字期间不触发发送或 Esc 关闭。加粗按钮将光标或选区放在标记内部，方便继续写。编辑时发送按钮提示为“保存修改”。 |
| [多级标签](https://help.flomoapp.com/basic/tag.html)：标签直接出现在正文，多级路径组织主题 | 保留 `#父/子`、空格结束及最近使用候选。重新打开输入面板时清除上一条记录的候选；侧栏读屏名称保留完整标签路径。标签重命名和批量删除不在一期范围。 |
| [快捷搜索](https://help.flomoapp.com/advance/search.html)：组合条件聚焦材料 | 当前关键词仍按整段包含匹配，与标签、类型、单日条件共同生效。显示全部已选条件，支持逐项取消和清除全部；关闭搜索框后，关键词条件仍可见。输入不被刷新夺走焦点，中文组合输入结束后再查询，切换条件回到结果顶部。 |
| [热力图与统计](https://help.flomoapp.com/advance/notes-graph.html)：用日期定位笔记，区分今天与选中日期 | 今天保留绿色轮廓，选中日期增加蓝色轮廓及读屏状态；日期显示为 `yyyy-MM-dd`。已有其他筛选时，不再把“全部笔记”标为选中。 |

收起搜索框只是隐藏输入框，不等于取消搜索。条件没有命中时保留条件，用户可直接移除其中一项，无需猜测当前还剩哪些限制。

展开／收起长卡片时同步按钮文字、提示和读屏状态。输入面板与其上方格式菜单分别记住返回焦点；卡片菜单转入删除确认后，取消仍返回原卡片操作入口。

## AI 解读

[官方 AI 洞察说明](https://help.flomoapp.com/ai/insight.html) 的可借鉴部分是：单条笔记可以得到回应，多条笔记可以连接主题，解读附来源，并可聚焦所选材料。帮助页没有公布内部提示词。

轻墨统一使用 [qingmo-insights](../../skills/qingmo-insights/SKILL.md)，仅按本次视角读取对应 Reference。它仍是待接入资源，不在一期界面增加 AI 入口。

- 单条记录围绕具体经历、困惑或取舍展开，不虚构长期模式。
- 多条记录结合时间、反例和原文归属理解变化，不把摘录当成作者自己的经历。
- 每个主要判断附可回到原始速记的引用；同一天的不同记录仍分别引用，未提供的记录不作为已读证据。
- 用户提出具体问题时先回应问题。普通回顾不强制输出行动清单，重新解读也不为求新鲜而反转事实。

公开 Skill 的方法来源、commit 与许可继续保留在 [sources.md](../../skills/qingmo-insights/references/sources.md)，没有新建零散提示词或提示词测试。

## 保留的差异与后续参考

| 主题 | 官网与轻墨的边界 |
|---|---|
| 搜索语义 | flomo 支持空格分隔的多个关键词、日期范围及标签排除。轻墨一期约定连续文本包含匹配和单日筛选；改成多词匹配或增加范围／排除，需要另行确认，不在本次改动中。 |
| 周起始日与天数 | 官网热力图按周一到周日，统计记录天数。轻墨已定周日起始，天数是首条记录到今天的日历跨度；保留既定口径，不把这两种天数混称为同一个统计。 |
| [每日回顾](https://help.flomoapp.com/advance/lucky.html) | 官网的材料范围和条数选择可作为二期交互参考。轻墨仍按已定的“同一天固定抽样、本地执行”实现，暂不增加提醒推送或更改抽样规则。 |
| [随机漫步](https://help.flomoapp.com/advance/random-walk.html) | 当前官网沿笔记间关联游走。轻墨二期约定本地随机展示历史速记，不据此引入向量检索、AI 关联或行走轨迹。 |
| [引用批注](https://help.flomoapp.com/advance/thread.html) | 官网可快速引用、批注和复制笔记链接。轻墨保留原生块和“在思源中打开”，关联整理沿用思源；`@` 检索、批注入口留待单独确定。 |
| [历史版本](https://help.flomoapp.com/basic/history.html)与[存储导出](https://help.flomoapp.com/basic/storage.html) | flomo 的历史保留期限、附件范围和空间额度属于其服务规则。轻墨沿用思源的历史、备份与导出，不承诺 flomo 的恢复期限或创建自己的回收站。 |

本次只做本地细节完善。构建和代码检查不代表原生输入法、手机键盘及双设备同步已验收；安装自用前仍执行一期计划中的 V1–V3。
