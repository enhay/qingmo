# 轻墨 · 设计规格

- 版本：v0.1，2026-10-11
- 依据：flomo iOS 截图 5 张，见 [reference/](reference/)
- 对应需求：[轻墨-PRD.md](../轻墨-PRD.md)

## 0. 原则

1. **布局、尺寸、间距、字号、交互照着 flomo 做**，目标是叠图对比时偏差不超过 ±1pt（验收方法见第 7 节）。
2. **品牌色和 logo 向思源靠**。主色从 flomo 的绿（色相 148°）往思源蓝（219°）挪一点，定为色相 165° 的"墨青"。标签和链接直接用思源蓝（加深后的版本）。
3. **有 3 处为了达到无障碍要求（WCAG AA）故意和 flomo 不一样**。flomo 原版这几处的对比度不达标：
   - 主按钮和选中行：flomo 是白字压在亮绿 `#30CF79` 上，对比度只有 2.0:1。轻墨改用深一些的墨青 `#158468`，白字对比度 4.6:1。
   - 次要文字（时间、计数、说明）：flomo 约 `#8D8D8D`，在白底上 3.3:1。轻墨改为 `#737373`，4.7:1。
   - 链接和标签：思源蓝 `#3575F0` 在白底上只有 4.2:1，轻墨加深为 `#2C66DC`，5.2:1。

   亮绿只用在不承载文字的装饰上：热力图、进度点、光标、今日框。
4. **思源界面里的部分不照搬 flomo**：悬浮按钮、侧滑面板入口、桌面端侧栏都用思源的 CSS 变量，跟随用户的思源主题。只有轻墨自己的全屏层用本文的固定配色，并跟随思源的亮色/暗色模式（读 `window.siyuan.config.appearance.mode`）。

### 2.2 侧边栏，对照 01

- **展开方式**：主页面整体右移 334pt，主页面的左上和左下角变成大圆角（约 48pt，和设备圆角接近），不加遮罩。侧边栏在下层，背景 `--qm-bg`。
- **收起**：点主页面露出来的部分，或者向左滑。

| 区域 | 规格 |
|---|---|
| 顶部 | 顶边 = 顶部安全区。左边 30pt 处是"轻墨"字标（18pt 粗体 `--qm-text`）；flomo 的"升级 PRO"徽章轻墨不做。右边是设置按钮：flomo 是一个 106×44pt 的胶囊装两个图标（铃铛和设置），轻墨只有设置一个，**改成 44pt 圆形**，样式同顶栏按钮 |
| 统计 | 顶边 129pt；三列，左边距 30pt，列宽 104pt。数字 28pt 中粗体 `--qm-text-secondary`，用等宽数字；标签 12pt `--qm-text-secondary`，和数字间距 6pt。依次是：笔记、标签、天数 |
| 热力图 | 顶边 189pt；12 列 × 7 行；格子 16pt 宽 × 17pt 高，横向间距 6.3pt，纵向间距 6.3pt；圆角 4pt。颜色分 5 档，见 3.1 的 `--qm-heat-*`。今天的格子加 1.5pt 的 `--qm-brand-bright` 描边。第 0 行是周日 |
| 月份 | 热力图下方 10pt；12pt `--qm-text-secondary`；对齐到该月第一周所在的列 |
| 菜单 | 菜单从 392pt 开始；每行高 40pt；左边距 16pt，宽 290pt |
| 选中行 | 背景 `--qm-brand`，圆角 12pt；图标和文字都是白色；右边 16pt 处有一个展开箭头（20pt，白色） |
| 一级菜单 | 图标 20pt，中心距左边 37pt；文字 15pt `--qm-text`，左边距 53pt |
| 二级菜单（全部笔记下面的筛选） | 文字左边距 83pt，图标中心距左边 66pt；左边距 36pt 处有一条 1pt 的竖线 `--qm-border`，贯穿所有二级项 |
| 一期菜单内容 | 全部笔记，以及它下面的有图片、有链接、无标签；然后是标签列表（树形，后面带条数） |
| 二期新增 | "有语音"筛选、AI 洞察入口 |
| flomo 有、轻墨不做 | 微信输入、AI agent、认知地图、回收站 |

### 2.3 输入面板，对照 03

- **出现方式**：点击底部输入条后，面板从底部升起，贴在键盘上方。键盘以外的区域盖一层 `--qm-scrim-blur`（背景模糊 20pt 加白色 60%）。
- **位置**：左右边距 12pt（宽 377pt）；面板底边 = 键盘顶边往上 12pt；面板高度 203pt。输入内容超过 8 行时面板变高，最高到顶部安全区下方 16pt，然后在内部滚动。
- **容器**：白底，圆角 20pt，`--qm-shadow-sheet`。

| 部位 | 规格 |
|---|---|
| 拖动条 | 36×5pt，圆角 2.5pt，`--qm-border`，距面板顶 10pt，水平居中；向下拖可以收起面板 |
| 输入区 | 左边距 18pt，顶边距面板顶 20pt；15pt，行高 24pt；提示文字"现在的想法是…"，`--qm-text-placeholder`；光标颜色 `--qm-brand-bright` |
| 工具栏 | 图标中线距面板底 29pt；图标 20pt，`--qm-text` |
| 工具栏图标位置（中心到面板左边的距离） | `#` 30pt、图片 70pt、分隔线 99pt、**B** 129pt、列表 168pt、分隔线 198pt、`⋯` 228pt |
| 分隔线 | 1×18pt，`--qm-border` |
| 麦克风（二期） | 40pt 圆形，背景 `--qm-fill`，图标 20pt `--qm-text-secondary`；右边紧挨发送按钮，间距 4pt |
| 发送 | 58×40pt 胶囊，距面板右边 12pt。**不可发送**时背景 `--qm-fill`，图标 `--qm-text-disabled`；**可发送**时背景 `--qm-brand`，图标白色 |
| 触控区域 | 所有图标按钮的点击区域都扩到至少 44×44pt |

### 2.4 AI 洞察（二期建入口，AI 视角预留），对照 05

**结构**：AI 洞察是一个"视角"列表，每日回顾是其中的一个视角。

| 部位 | 规格 |
|---|---|
| 顶栏 | 左边是关闭按钮（44pt 圆形，同顶栏按钮）。flomo 右边有"历史 + 新建"胶囊（102×44pt），轻墨等 AI 视角上线时再加 |
| 标志 | 36pt 的圆环，中心距顶 166pt，渐变从 `--qm-link` 到 `--qm-brand-bright`（替换 flomo 的蓝绿渐变环） |
| 标题 | "选择任意视角，开始洞察"，20pt 中粗体，同样的渐变色（`background-clip: text`），标志下方 24pt |
| 范围胶囊 | 标题下方 18pt；高 32pt，圆角 16pt，背景 `--qm-brand-tint`；13pt `--qm-brand`；内容"已选全部，共 n 条笔记 · 修改范围"。只读视角（如每日回顾）不显示 |
| 视角列表卡片 | 顶边 296pt；左右边距 12pt；白底，圆角 12pt；每行高 64pt，不加分隔线 |
| 行内布局 | 左边 30pt 处是 34×30pt 的线条图标（`--qm-text`）；标题从 76pt 开始，16pt 中粗体 `--qm-text`，后面隔 10pt 是来源 13pt `--qm-text-secondary`（例如"by 轻墨"）；说明在标题下方 6pt，13pt `--qm-text-secondary`，单行截断；右边 32pt 处是箭头（9×17pt，`--qm-text-secondary`） |
| 底部"发现更多视角"卡片 | 等 AI 视角上线时再做：左右边距 28pt，高 51pt，圆角 12pt，白底加 `--qm-shadow-float`，文字 15pt |
| 二期的视角 | ① **每日回顾**：说明"让过往的记录，重新焕发价值"；② **随机漫步**：说明"随机翻开一条，与过去的自己相遇"。两个都不需要 AI，也不需要选择范围 |
| 预留的 AI 视角 | 默认洞察、价值澄清、逆向思考、二阶思考等。**没做出来之前不在列表里显示，不放灰掉的占位项**。数据结构见 PRD 第 6 节 |
| AI 未配置 | AI 视角上线后，如果思源里没有配置 AI 模型：行照常显示；点击后弹出底部面板，提示"在思源「设置 → AI」里添加模型后即可使用"，下面一个主按钮"去设置"（`--qm-brand`，高 48pt，圆角 12pt） |
| 洞察进行中 | 列表卡片的位置换成进度状态：顶部是视角名，下面是"正在洞察…"（15pt `--qm-text-secondary`）和一个 3 点的跳动动画（`--qm-brand-bright`），底部是"取消"文字按钮。开启"减少动态效果"时不跳动，只显示文字 |

### 3.1 颜色

```css
:root {                              /* 亮色模式，对应思源亮色 */
  --qm-bg: #F9F9F9;                  /* 页面，测量值 */
  --qm-surface: #FFFFFF;             /* 卡片、面板 */
  --qm-fill: #ECECEC;                /* 不可用按钮、麦克风底色，测量值 */
  --qm-border: #E8E8E8;              /* 分隔线、竖线，测量值 */
  --qm-border-strong: #D9D9D9;       /* 圆形按钮描边，测量值约 #D0D0D0 */
  --qm-text: #333333;                /* 正文，测量值 #3D3D3D，JPEG 会偏浅 */
  --qm-text-secondary: #737373;      /* 改动：flomo 约 #8D8D8D，为对比度加深 */
  --qm-text-placeholder: #A6A6A6;    /* 提示文字，测量值 #969696–#BFBFBF */
  --qm-text-disabled: #C8C8C8;
  --qm-brand: #158468;               /* 墨青：按钮、选中行，白字对比度 4.6 */
  --qm-brand-bright: #20C59C;        /* 只用于装饰：光标、进度点、今日框、分页点 */
  --qm-brand-tint: #E6F5F0;          /* 范围胶囊等浅底 */
  --qm-link: #2C66DC;                /* 思源蓝 #3575F0 加深，白底对比度 5.2 */
  --qm-link-tint: #EEF3FE;           /* 标签胶囊底色，测量值 #EFF2FB */
  --qm-heat-0: #EFEFEF;              /* 当天 0 条，测量值 */
  --qm-heat-1: #BDEBDD;              /* 1–2 条 */
  --qm-heat-2: #7DD9BD;              /* 3–5 条 */
  --qm-heat-3: #20C59C;              /* 6–9 条 */
  --qm-heat-4: #158468;              /* 10 条及以上 */
  --qm-danger: #D93636;              /* 删除确认 */
  --qm-scrim: rgba(0,0,0,.21);       /* 测量值：#F9F9F9 被压到 #C5C5C5 */

}
```

### 3.3 间距、圆角、阴影、动效

- **间距刻度**：4 / 6 / 8 / 10 / 12 / 16 / 20 / 24 / 28。页面左右边距：卡片 12pt，顶栏按钮 16pt，底部输入条 28pt。

  - `--qm-shadow-float: 0 2px 12px rgba(0,0,0,.06)`：圆形按钮、底部输入条
  - `--qm-shadow-sheet: 0 8px 32px rgba(0,0,0,.10)`：输入面板、回顾卡片
