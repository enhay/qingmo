# 轻墨 · 设计规格

- 版本：v0.2，2026-10-14（补二期新增界面）
- 依据：flomo iOS 截图 5 张，见 [reference/](reference/)；flomo 桌面版 5.26.93 安装包的样式与组件结构（第 1 节）
- 对应需求：[轻墨-PRD.md](../轻墨-PRD.md)

## 0. 原则

1. **布局、尺寸、间距、字号、交互照着 flomo 做**，目标是叠图对比时偏差不超过 ±1pt（验收方法见第 7 节）。
2. **品牌色和 logo 向思源靠**。主色从 flomo 的绿（色相 148°）往思源蓝（219°）挪一点，定为色相 165° 的"墨青"。标签和链接直接用思源蓝（加深后的版本）。
3. **有 3 处为了达到无障碍要求（WCAG AA）故意和 flomo 不一样**。flomo 原版这几处的对比度不达标：
   - 主按钮和选中行：flomo 是白字压在亮绿 `#30CF79` 上，对比度只有 2.0:1。轻墨改用深一些的墨青 `#158468`，白字对比度 4.6:1。
   - 次要文字（时间、计数、说明）：flomo 约 `#8D8D8D`，在白底上 3.3:1。轻墨改为 `#737373`，4.7:1。
   - 链接和标签：思源蓝 `#3575F0` 在白底上只有 4.2:1，轻墨加深为 `#2C66DC`，5.2:1。

   亮绿只用在不承载文字的装饰上：热力图、进度点、光标、今日框。
4. **思源界面里的部分不照搬 flomo**：悬浮按钮、侧滑面板入口、桌面端侧栏都用思源的 CSS 变量，跟随用户的思源主题。只有轻墨自己的全屏层用本文的固定配色。手机端全屏用本文第 2.1–2.3 节的手机布局；桌面端在思源标签页里用 2.6 节的两栏布局，并跟随思源的亮色/暗色模式（读 `window.siyuan.config.appearance.mode`）。

#### 2.2.1 标签区（二期），参照 flomo 桌面版

结构照 flomo：标签区分"常用"和"全部标签"两组，常用在上。flomo 叫"置顶标签"，轻墨叫"常用"，避免和笔记置顶混淆。

| 部位 | 规格 |
|---|---|
| 分组标题 | 12pt `--qm-text-secondary`，行高 12pt，标题行最低 28pt，下边距 4pt，左边与标签文字对齐。分组之间间距 20pt（flomo 同值） |
| 常用组 | 至少有一个常用标签时才显示。标题"常用"右边跟一个 12pt 的 `chevron-right`，展开时转 90°；点标题收起或展开整组，状态只存本机。组内每行显示完整路径（如 `#读书/随想`）和条数，不显示层级；点击走同一个标签筛选 |
| 全部标签组 | 标题沿用现有"标签"。标题行右边是查找按钮（`search` 16pt，`--qm-text-secondary`；手机常显，点击区域 44pt；桌面在标签区悬停或获得焦点时出现，28px 方形、圆角 8px，flomo 同款） |
| 查找条 | 点查找按钮后替换标题行：手机高 36pt、桌面 28px；背景 `--qm-fill`，圆角 8pt；左边 14pt 搜索图标，输入框 13pt，提示"查找标签"；右边清除按钮（`x` 12pt，点击区域 44pt／桌面 24px）。点清除或按 Esc 关闭查找，恢复原来的展开状态。命中的字用 600 字重 `--qm-text` 标出；没有命中时在查找条下方显示"没有匹配的标签"，12pt `--qm-text-secondary`，上下内边距 12pt |
| 展开按钮 | 有子标签的行在标签名左边放 `chevron-right`（14pt，`--qm-text-secondary`，展开时转 90°），按钮 24pt 见方、点击区域 44pt（手机）／28px（桌面）；没有子标签的行留同宽空白，保证名字对齐。点按钮只展开或收起，不触发筛选；`aria-expanded` 反映状态 |
| 层级缩进 | 每级缩进 16pt；子级左边一条 1pt `--qm-border` 竖线，竖线在上一级展开按钮的中线上（flomo：子列表左外边距 17px、内边距 12px、1px 竖线） |
| 行尾 | 条数 12pt `--qm-text-secondary`；条数右边是"⋯"按钮（`ellipsis` 16pt，`--qm-text-secondary`，点击区域 44pt）。手机常显；桌面悬停或获得焦点时出现，flomo 桌面在悬停时用"⋯"占掉条数的位置，轻墨两者都留 |
| 标签菜单 | 点"⋯"弹出 2.7 同款菜单，只有一项："加入常用"（`pin`）或"移出常用"（`pin-off`）。操作后在原地提示"已加入常用"／"已移出常用"，失败提示"没有保存成功" |
| 行高 | 手机沿用 2.2 的菜单行高 40pt；桌面沿用 2.6 的标签行高 34px |

#### 2.3.1 引用续写（二期）

- 从卡片菜单"引用续写"进入。面板打开时第一段是来源摘录，样式同 2.1.1 的"引用"，光标在下一段的空行。
- 摘录是一个整体：不能把光标放进去改字；光标在摘录后一段的开头按退格，整段摘录一次删掉。
- 已有未发送的新建草稿时，先弹确认框："用引用续写替换当前草稿？"，按钮"替换"（`--qm-brand`）和"取消"。取消后草稿不变。
- 工具栏不新增引用按钮；flomo 用 `@` 插入引用，轻墨本期不做。

#### 2.3.2 录音（二期，推断）

flomo 桌面版没有可参照的录音界面，以下全部是推断，按现有 token 定。

| 状态 | 规格 |
|---|---|
| 开始 | 点面板里的麦克风，或从底部输入条长按进入。第一次录音由系统弹出麦克风授权 |

## 5. Logo 方向

- **字标**："轻墨"两个字，用系统字体的粗体，字距 +2%。
- **图形**：插件图标复用 `src/index.js` 中 `iconQingMo` 的便签、文字线、半透明墨浪和墨滴路径，统一使用墨青 `#158468`，透明背景。导出 160×160 的 `icon.png`，四周保留留白。
- 顶栏与侧栏图标取 logo 图形的单色线性简化：带倾角的便签卡片、两道文字线、底部半透明（35%）墨浪、右下实心墨滴；线宽 1.7、圆角端点，与思源自带的 Lucide 风格图标一致，颜色跟随思源主题。
