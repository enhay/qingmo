# 流式洞察与 flomo 提示词核对

验证日期：2026-10-28。依据[流式洞察计划](../../../plans/2026-10-28-streaming-insights.md)。本轮仅本地实现及隔离验证，没有浏览器截图、真机验收或发布。

## 本地实现

AI SDK 7 与 Svelte Chat 负责消息、流式协议、停止与模型请求。配置从思源运行时读取，OpenAI Chat Completions、OpenAI Responses、Anthropic 分别交给对应 SDK Provider；账号登录认证和其他协议明确提示不支持，不回退旧接口。真实服务验证范围是当前 OpenAI 协议模型，其他协议仅完成 SDK 接线。

一个对话使用一个思源原生文档，完整问答逐轮追加；停止、截断和来源无效的回答不自动归档。保存失败重试不再次调用模型。会话通过明确的 sessionId 在共享状态与页面间识别，避免 Svelte 代理对象的引用差异。旧结果属性与旧 AI 接口不兼容、不迁移。

提示词保留六视角方法，精简重复边界约束，补充当前追问、用户纠正和证据归属的自然交流规则。范围、来源核对、安全渲染及保存控制由代码承担。

## 验证结果

- 自动检查：20 条测试通过，格式检查、Vite 构建、`node --check dist/index.js` 与差异检查通过。
- 受控 SDK 流：验证第二轮携带已完成问答和用户纠正；停止后文字保留且迟到结果不归档；未知来源拒绝保存并不作为后续依据；属性保存失败仅补属性；服务商错误不输出含材料的 SDK 默认日志，也不自动重试付费调用。
- 一次性故障检查：截断、空输出、429、会话材料预算超限、模型变更及读取配置期间停止均通过相应错误码或未发生模型请求／文档写入验证。
- 编译后的 Svelte Chat 与共享状态：生成 sessionId 后共享会话标识一致，完整消息状态及保存文档 ID 可读回。用户文字中的标签、链接、HTML、查询和属性语法按文字保存，结果未自动加入速记集合。
- 真实模型：读取运行中的思源 3.8.8 配置，使用 AI SDK Svelte Chat 与 `deepseek-v4-flash` 进行两轮合成对话，共两次模型调用。第一轮首段文字约 2066ms；第二轮收到“周二会议是我主动约的，因为协作更重要”的补充后，转而讨论主动取舍。该时间是单次观察。
- 隔离思源：读写仅发生在 `.scratch/streaming-insight-kernel/workspace`，两轮保存为同一文档 `20261028145237-ej6ezxc`；按新属性查询历史可读回该文档，未加入速记收录，原合成材料保留。当前个人工作空间仅用于读取 AI 配置；没有读取或修改个人笔记。

生成中的布局、滚动、键盘、安全区、手机直连和最终视觉体验仍由用户验收。会话只在当前插件实例中保留，历史点击在思源打开文档，不恢复为可续聊会话。
