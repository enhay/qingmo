使用本机 SiYuan 3.8.6 的真实内核、`.scratch/kernel/` 隔离工作空间及合成笔记；浏览器连接 `127.0.0.1:6817` 的宿主桌面页与移动网页。未写入个人笔记，未部署或发布。移动视口为 402 × 874，桌面为 1280 × 900；这些结果不代表 iOS/Android 真机通过。

## 已验证行为

| 路径 | 观察结果 |
| --- | --- |
| 思源块菜单 → 插件 → 加入轻墨 → 卡片 → 移出确认 → 原块读回 | 两个收录属性写入后卡片出现；移出后卡片消失，原段落及其原位置仍在，两项属性清除 |
| 原生标签与统一集合 | 段落、列表项、引用、超级块按约定粒度收入；属性与标签重复命中只计一次；标题只收入自身；代码和多级标签不误收；嵌套列表的外层不误收 |
| 整篇笔记标签 | 原生文档标签含「轻墨」时只显示一张整篇卡片，正文标题后的内容也可搜索；文档标签、正文标签共同参与筛选与统计，回顾集合与列表总数一致 |
| 整篇笔记移出 | 实际菜单确认后只移除文档的「轻墨」标签，其他文档标签、正文、块 ID、父子关系及创建时间保留；内部一条手动加入和一条正文标签收录恢复展示；「轻墨/项目」不触发整篇收录 |
| 操作与格式菜单 | 桌面、移动亮暗主题截图通过；操作面板贴近按钮，操作行高 44px；宽编辑器直接显示有序列表、引用，窄屏显示更多菜单；Tab 循环、Escape 关闭及焦点返回通过，格式操作插入当前行首 |
| 搜索、标签、统计 | 第二段关键词能找到所属卡片；标题后的正文不归入标题搜索；列表 ID 与统计总数一致 |
| 编辑外部内容 | 普通段落保留 ID、类型、父块、created 与属性；块自身属性不作为卡片或编辑正文显示，保存仍保留；超级块可增加段落和列表；纯标签收入编辑后不补收录属性 |
| 原文定位 | 原文档已打开并滚动到别处时，点击来源会切回原文档并滚动、高亮目标块；移动网页关闭轻墨后目标块可见。修复前仅切页，目标块仍在视口外；此次复验使用隔离宿主浏览器，未操作个人桌面客户端 |
| 移出与内容保留 | 混合来源同时清属性及原生标签，其他标签和属性保留；引用子块 ID 保留；表格加入再移出不改结构；加粗、链接形式的原生标签可取消，代码及 URL 原文保留 |
| 原生速记回归 | 新建、编辑、删除继续工作；外部内容不能走原生整块删除入口 |
| 每日回顾 | 重入及重载保持同日顺序；数量从 5 改为 3 后保存，顺序不变；前后翻页及原生定位成功；移出或删除的 ID 被剔除 |
| 随机漫步与返回 | 多条记录时下一条不与前条相同；快速进入每日回顾并立即返回后，旧请求不会追加卡片到视角列表 |
| 保存前确认 | 使用宿主 Lute 和真实提交事件验证：保留加粗的原生标签不误提示；仅剩代码内同名字样时先确认，取消后不调用保存。该探针拦截写入，未修改笔记 |
| 空、单条、失败状态 | 临时控制浏览器仓库查询返回值：空集合显示空状态；单条可反复阅读；读取失败显示重试，恢复真实查询后可重新加载。此项是 UI 边界模拟，不是内核故障实测 |

普通段落改成多段、列表、引用等结构时，轻墨会要求在思源中编辑。真实内核的单段落写回会丢弃后续独立段落，因此没有把这种写入当作成功。

## 自动检查与性能

`npm test` 的 12 项测试通过；`npm run build`、`node --check dist/index.js` 和 `git diff --check` 通过。新增测试覆盖每日排序的确定性、输入不变、空/单条返回值，以及正文与块自身元数据分离、子块属性及代码原文保留、整篇预览和文档标签的精确移除；复杂块语义使用真实内核 API 与 SQL 读回验证。

文档标签扩展前的二期性能测量：隔离内核 5000 条合成记录，首屏读取 20 条约 **654ms**，统计约 **252ms**，第二页约 **632ms**；前两页 40 个 ID 无重复。这是一次本机数据读取测量，包含事务刷新及正文读取，不是手机完整页面耗时或并发容量结论；本轮未重测 5000 条性能。

## 卡片正文直接复制

思源桌面样式中的 `.layout-tab-container` 设置了 `user-select:none`，卡片正文原来未覆盖该设置。现仅对 `.qm-body` 显式允许选择，卡片流和回顾共用此正文样式。

浏览器使用实际界面与合成内容，给祖先容器施加宿主同样的禁选规则：修复前鼠标双击无选区；修复后鼠标拖选能取得对应正文，原生复制命令返回成功，copy 事件中的选区与所选文字一致。构建与差异检查通过。自动化快捷键未触发复制事件，剪贴板读取权限被拒绝，因此本次不声称验证了桌面客户端的快捷键复制到其他应用。

右键菜单补充：有选区时显示「复制所选文字」，打开菜单前保存选区文本；无选区时展示完整卡片操作，和右上角菜单共用实现。链接与图片在无文字选区时保留宿主右键行为。卡片菜单去掉图标，非段落／超级块只保留「在思源中打开」，不重复展示相同跳转的编辑入口。菜单按鼠标位置显示并限制在轻墨窗口内。

本轮浏览器已实测鼠标拖选→右键→复制，并通过调试连接仅为本地测试页面授予剪贴板读取权限，读回实际 Clipboard API 内容：所选复制与打开菜单前的选区完全一致；整条复制与该卡片完整正文一致。右上角菜单 Escape 关闭后焦点回到原入口。12 项测试、构建和产物语法检查通过。此证据覆盖本地 Chromium 界面与剪贴板，思源桌面客户端仍需重载后验收。截图：[选中文字右键复制](card-copy/01-选中文字右键复制.png)、[纯文字卡片菜单](card-copy/02-卡片纯文字右键菜单.png)。
