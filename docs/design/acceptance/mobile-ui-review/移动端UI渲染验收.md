## 验证

- `npm test`：14 项通过；`npm run build`：通过、无 Svelte 警告；`node --check dist/index.js`、`git diff --check`：通过。
- 现有原生编辑器临时探针通过：引用与音频 ID／属性往返、草稿、清除待转写标记、代码内容保留、粘贴净化。未新增只断言样式或文案的永久测试。
- Chrome：402×874、320×740、1280×900；亮色／暗色。合成 WAV 可播放，播放器 `data-state` 进入 `playing`；录音使用 Web Audio 合成流，没有调用真实麦克风或识别服务。
- 范围应用后，共享设置与范围查询收到同一个 `阅读/随想` 标签；开始日期晚于结束日期时，两行 `aria-invalid=true`，应用禁用；取消保留原范围。
- 标签菜单 Esc 后焦点返回“标签操作”；常用组折叠时 `aria-expanded=false`。
- iOS 全屏 WKWebView：402×874，顶部／底部安全区分别 62／34px。输入条矩形 `(28,788,346,48)`、麦克风 `(326,790,44,44)`；洞察顶栏 `(12,62,378,60)`。
- 隔离宿主：插件挂载、设置打开、历史洞察进入 `history`、设置保存失败保留原值及卸载通过。实际卡片中的来源摘录、音频时长、逐段待转写状态已观察，见 [宿主截图](20-isolated-host.png)。

## 验证边界

旧 `.scratch/mount-smoke.cjs` 的材料准备 `ready` 断言本轮失败。检查实际错误后确认：新启动的隔离宿主未配置编辑模型，页面显示对应配置提示。没有修改测试预期来冒称真实模型通过；临时检查另外确认了该错误分支及历史／设置路径。确认、生成、结果和历史的视觉覆盖使用合成返回。

模拟器证据证明 WebKit 安全区下的布局，不代表思源 iOS 真机、系统键盘、真实麦克风授权或跨设备同步已验收。未修改规格中标注“推断”的尺寸，也未宣称与 flomo 全部页面达到 ±1pt。最终真机视觉由用户验收。
