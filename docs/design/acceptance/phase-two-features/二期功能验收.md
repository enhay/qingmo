## 同路径修复

- 编辑器加载已有音频笔记时，从原始 Markdown 保留身份与属性，避免渲染 HTML 导致音频丢失。
- 历史内容的不可编辑标记先转为 Lute 可转换的结构，音频属性单独保留，防止恢复时变成 HTML 或丢掉待转写状态。
- 手动转写逐段保存并留历史；等待期间如果笔记正文发生变化，停止写回并提示重新打开。使用受控迟到识别响应与真实内核编辑验证，新内容和待转写录音均保留。
- 思源 `saveData` 返回非零结果时视为保存失败，不把失败设置同步到已开视图。
