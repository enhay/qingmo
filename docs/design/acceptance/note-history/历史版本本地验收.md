# 历史版本本地验收

2026-10-12，在隔离的思源 3.8.5 内核与桌面 Web 宿主中验证，不使用个人笔记。

## 界面

卡片菜单进入「历史版本」，左侧时间倒序排列，选中后右侧显示该条笔记的原格式内容。空历史左侧显示灰底提示，右侧留空。保留期限使用思源设置说明。窄屏分为时间列表与详情，可返回列表。

## 实际消费路径

- 点击时间切换预览，只显示目标笔记，排除同文档邻居；相邻相同内容的快照合并展示。
- 打开编辑后不改内容直接保存，原块内容和历史数量均保持不变。
- 编辑前创建思源历史并读回确认。思源异步提交历史索引，创建接口成功后可能短暂查询不到；此时最多等待 5 秒，每 250 毫秒核对一次，接口报错或等待结束仍未匹配就停止覆盖。
- 新建唯一内容后，通过轻墨首次编辑保存成功，旧内容可在历史中预览。再次恢复后，API 确认原块 ID、父文档、邻居内容未变，恢复前内容也已归档。
- 恢复带列表、加粗、下划线、高亮组合及标签的版本后，API 确认格式与标签保留，根块收录属性及自定义属性保留。
- 另存历史为新速记生成新 ID，原笔记不变，不继承历史根块自定义属性。
- 存在草稿时取消恢复确认，持久草稿和原笔记均不变。
- 模拟历史读取请求失败，面板进入错误状态；恢复网络后点击重试，重新选中历史。
- 单元测试验证历史留存失败时返回对应错误码，持久正文及属性不变。

顺带修复了此路径暴露的列表预览问题：保留思源列表标记及有序列表起点，避免转换时丢失列表格式。

## 验证边界

使用已有测试与构建检查。历史版本由思源管理，同秒快照可能合并，保留期限取决于思源设置，图片依赖原资源。未发送草稿不计入历史。复杂结构、子块自定义属性及超大文档不承诺在轻墨恢复；复杂结构提示到思源处理，超大文档读取会报告失败。

未完成真实移动客户端、跨设备同步、超大历史量翻页与资源丢失的端到端验收。界面窄屏证据来自桌面浏览器调整视口。
