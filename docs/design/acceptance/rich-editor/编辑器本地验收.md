# 标签候选与所见即所得编辑器验收

2026-10-12。Sol 实现，主代理在独立工作区的思源内核 `127.0.0.1:6817` 与真实桌面网页插件中验收。测试笔记均为隔离样本，未写入个人笔记。

## 已观察结果

| 操作 | 结果与证据 |
| --- | --- |
| 输入 `#城市` | 浮层匹配历史多级标签 `旅行/城市漫步`；上下键主动选择后 Enter 替换当前输入。 |
| 输入 `#alpha` | 匹配 `ProjectAlpha`，验证名称中间匹配与大小写不敏感。 |
| 输入相似短名称后直接 Enter | 确认为输入的名称，没有误用更长的历史候选；无历史匹配也能创建。 |
| 发送历史标签和新标签 | SQL `blocks.tag` 读回 `#旅行/城市漫步# #全新想法#`，可由既有统计和筛选消费。 |
| 开启加粗、下划线、高亮后连续关闭 | 三格式文本保存为 `textmark strong mark u`；后续普通正文没有格式 span。 |
| 从卡片再次编辑、保存 | 同一块 ID 的格式与原生标签保持，轻墨属性仍为 `1`；卡片与编辑框均无 Markdown 星号泄漏。 |
| 列表中连续 Enter，空项 Enter | 继续下一项、退出列表到普通正文；发送后原生列表仍有两项，再次编辑内容保持。 |
| 编辑内联图、代码与链接样本后保存 | 图片位置、说明和资源路径保持；代码中的三连续换行、`#代码字面` 和属性示例原文保持，代码没有成为标签。图片实际加载成功。 |
| 模拟保存请求失败后刷新 | 输入与本机草稿保留，发送按钮恢复可用，刷新可恢复草稿。 |
| 原生撤销、重做 | 本机草稿依次读回输入值、撤销前值、原输入值。 |
| 模拟组合输入事件 | 组合状态 Enter 不确认标签；结束组合后 Enter 才确认。此项不代替真实输入法。 |
| 粘贴含脚本、事件与危险链接的 HTML | 脚本与事件不执行，危险 URL 被移除。 |

SQL 读取前均刷新思源事务。代表性隔离样本：标签与列表 `20261012134613-tjdyza1`；组合格式 `20261012134938-66m68h5`；代码与内联图片 `20261012135428-f8js3ff`。

## 实现与证据边界

草稿仍只保存在本机 localStorage。发送沿用原保存入口。为准确显示思源实际保存的相邻组合格式，每张卡片并行读取 Kramdown 与原生 DOM，比原来增加一次本机读取；没有增加远端存储或依赖。本轮未重跑 5000 条性能样本。

含复杂原生结构或子块自定义属性的内容交回思源编辑，不以丢弃结构换取可编辑。普通段落仍不能在轻墨内改成多段或列表。

`npm test` 12 项通过；保留既有行为断言，仅补齐新增原生 DOM 请求的测试数据。构建、语法及差异检查通过。新交互以实际浏览器、截图和 API/SQL 读回验收，没有添加依赖 DOM 层级或 CSS 类名的单元测试。

尚未覆盖：真实中文输入法、iOS/安卓软键盘、设备同步，以及大数据量下新增 DOM 读取的性能。上述项目不能由本地浏览器结果替代。
