# 腾讯云与 AI 宿主约束实测

2026-10-14，二期计划 Delivery 2、3 的本机可验证部分。仅使用合成语音与隔离思源 3.8.6；密钥运行时读取用户指定工具的本机配置，未输出或写入仓库。

## 腾讯云

调用 `SentenceRecognition`（2019-06-14）、`16k_zh`，使用 TC3 签名。短合成语音 6.384 秒、WAV 204,372 字节、base64 272,496 字节：非浏览器直连成功，约 0.58 秒；内核转发成功，约 0.36 秒。识别把「轻墨」识别为「清末」，其余合成句基本一致，不能把成功返回视为逐字准确。

59 秒重复合成语音经真实内核转发成功，WAV 1,888,044 字节、base64 2,517,392 字节，约 1.04 秒，服务返回音频时长 59,000 毫秒。以上耗时为各单次请求，不是性能分布。

跨域预检返回 HTTP 200，但不包含 `Access-Control-Allow-Origin/Headers/Methods`，正常浏览器不能据此直连。后续按绑定决定统一使用内核转发。`forwardProxy` 需要 `payloadEncoding: "base64"`，传签名时原始 JSON 字节的 base64；误用 `"text"` 会改变请求字节，实测返回签名错误。

无效 SecretKey 返回 `AuthFailure.SignatureFailure`；有效密钥但空 Data 返回参数错误。未持有无权限或欠费测试账号，没有制造这些账号状态。

**免费验证完整识别权限的前提未成立。** `DryRun: true` 实测返回 `UnknownParameter`，该接口没有官方独立的免费权限验证参数。空音频错误不能证明完整识别权限及服务可用，也没有账单证据支持把它称为免费验证。转写设置里的「验证」按钮行为需用户决定，尚未自行改成可能计费的识别测试。

官方依据：[一句话识别接口](https://cloud.tencent.com/document/product/1093/35646)、[计费说明](https://cloud.tencent.com/document/product/1093/35686)、[SiYuan 3.8.6 转发实现](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/api/network.go)。脱敏原始结果与临时探针在 `.scratch/host-probes/`。

## AI 与设备边界

隔离宿主未配置 AI provider 或编辑模型；个人宿主只读确认已有 provider 和编辑模型，没有复制凭据或调用个人宿主的共用上下文。需明确现有模型配置如何用于隔离验收后，才能完成真实生成、取消及清理验证。

合成音频由本机语音合成和 ffmpeg 生成，不是 MediaRecorder 或 Web Audio 证据。真实桌面麦克风授权、浏览器音频解码重采样、Android/iOS 录音格式与权限尚未通过；Delivery 3 不能据此标为整体完成。
