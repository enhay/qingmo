# 轻墨一期本地验收

2026-10-11。对应 [实施计划](../../plans/2026-10-11-phase-one.md)。结论：F1–F7 的本地插件实现已完成，隔离内核与浏览器消费链路通过；安装自用前仍须完成 V1–V3。本次没有安装到个人工作空间，没有发布。

## 环境与证据范围

- 思源 3.8.5 内核，独立工作空间位于项目 `.scratch/kernel/`；所有写入均为合成速记和测试图片。
- 真实思源 `browser-mobile`（402×874）和 `browser-desktop`（1280×900），Chrome 自动化操作；不是模拟的后端或静态界面。
- Node 22.23.1；无新增 npm 依赖。`npm run build`、`npm test`（6 项）、产物 `node --check` 均通过。
- 当前项目原本没有 Git 仓库，本次未初始化仓库或创建提交。原始 PRD、调研与设计文档未改动。

## 已观察到的行为

| 路径 | 结果 |
|---|---|
| 菜单／手机悬浮按钮 → 选择笔记本 → 输入 → 发送 | 真实内核生成每日文档及标记超级块，页面显示新卡片，发送后清除对应草稿 |
| 输入 10 段正文并上传 3 张图片 → 卡片 → 原生编辑器 | 正文折叠可展开，三张图片有缩略图；图片资源能读回，原生编辑器能显示正文和图片 |
| 卡片 → 编辑 → 保存 | 块 ID、`custom-qingmo-memo` 与另加的自定义属性保留；新正文可检索 |
| 卡片 → 删除确认 → 删除 | 从 API 与卡片查询中消失；确认文案说明思源文件历史恢复入口 |
| 在原生数据中取消速记标记 → 对旧卡片执行删除 | 返回 `MEMO_NOT_FOUND`，原内容仍在，未误删普通块 |
| 标签＋只在第二段出现的关键词 | 实际页面及 SQL 查询命中正确速记；引号等输入不改变 SQL 查询结构 |
| 图片／链接／无标签／层级标签筛选 | 与原生 spans 和块数据一致；代码里的图片源码不被计为图片；同条记录的两个子标签只给共同父标签计一次 |
| 当天修改笔记本或模板后发送 | 继续复用当天已标记文档；没有另建当天文档 |
| 中断发送请求 → 重载页面 → 恢复后发送 | 原文及本机草稿保留；重载后恢复；恢复发送成功后仅产生一条对应速记并清除草稿 |
| 桌面侧栏草稿 → 全屏编辑 → 回到侧栏 | 接续最新草稿，未被旧视图覆盖；快捷键 `⌥⇧Q` 能打开输入 |
| 开启启动入口 → 重载宿主 | 自动打开输入并恢复草稿；这不是原生 App 冷启动计时 |
| 移动网页端调用宿主 `goBack` | 先收起输入，再关闭轻墨回到思源；原生安卓返回键仍待设备验证 |
| 亮暗主题、主界面／输入／侧边栏的自动无障碍检查 | axe 4.12 检查到的最终页面为 0 violations；亮色三个页面及暗色卡片页没有 incomplete 项。此结果不等于完成全部人工无障碍验收 |

回归测试覆盖标签转换、代码围栏与空行保真、原生图片说明与位置保真、重复附件顺序、草稿隔离及存储失败。复杂原生内联图片保持 Markdown 原样进入编辑区；普通末尾附件仍以缩略图编辑。

## 性能

最后一轮为 5000 条合成速记，单次本机测量：

| 观察项 | 时间／结果 |
|---|---|
| 首页数据读取，含 20 条完整正文 | 533ms |
| 完整统计，含热力图与层级标签 | 243ms |
| 桌面侧栏刷新开始 → 数据、统计更新 → 两个绘制帧后 | 691ms |
| 第一、第二页 | 每页 20 条，共 40 个不同块 ID，仍有后续页 |

这些是本机合成数据结果，不是手机冷启动、跨设备同步或长期性能分布。压测文档已从隔离工作空间移除。
