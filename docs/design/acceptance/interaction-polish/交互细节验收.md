# 三轮交互细节验收

2026-10-16。范围为 PRD 6.9、设计规格 2.10 和 `2026-10-16-interaction-polish.md`。所有内核与界面操作使用 SiYuan 3.8.7 隔离工作空间 `.scratch/kernel`、端口 6817 和合成数据。用户本轮明确授权子代理进行视觉验收。

## 代码与原生数据

- 输入效率、卡片偏好、原生浮窗与计数、浏览、回顾历史、统计分别本地提交；未推送或发布。
- 最终格式检查、15 项测试、构建、`node --check dist/index.js`、`git diff --check` 通过。仅新增一条统计聚合测试，原有测试期望未修改。
- 独立回归通过：原生引用 API 读回、富文本编辑器往返、历史捕获与恢复保留块 ID 和引用、收录和搜索去重、置顶排序、草稿读写清除、嵌套标签。修复后另外核对真实历史 DOM 的字数不为零。未调用模型。
- 原生引用次数沿用思源 `fillBlockRefCount → QueryRefCountInBox` 的块级计数；子块被引用不累加到根卡片。引用方浮窗使用 `/api/block/getRefIDs` 返回的原生定义。
- 合成外部段落两处引用同一根块，原生 `getDoc` 的 `refcount` 与轻墨仓库均为 1；子块另被引用 1 次不累加根块。整篇收录被引 1 次，外部引用文档未自动收录；删除目标后仓库不再返回该卡片。这是当前原生数据的观察，没有在轻墨中另加去重规则。

## 统计

在隔离宿主创建 5000 条原生合成卡片，创建日期限定为 2032 年。SQL 聚合与历史 DOM 纯文本计数核对了多段容器、列表、表格、代码、引用、标签、图片说明及路径、音频、全角空白和 emoji。

| 范围 | 笔记数 | 字数 | 记录天数 | 单日最多条数 | 单日最多字数 |
|---|---:|---:|---:|---:|---:|
| 2032 年 | 5000 | 25012 | 4 | 4996 | 24980 |
| 2032 年 10 月 | 3 | 31 | 2 | 2 | 30 |

实现代理连续四次年度完整 API 请求为 40–42ms，月度为 35–36ms；主代理独立年度复验为 56.3ms，均包含仓库的事务刷新请求，低于 300ms。它们是当前运行内核中的测量，没有重启或清空操作系统缓存，不能称为冷启动耗时。

性能验证发现共享收录集合中的相关子查询以及逐叶子扫描图片数据导致原方案约 3.3s；按执行计划改成等价 ID 集合与一次分组后达到要求，随后重跑原生收录、历史与搜索回归。图片和标签的非正文部分在 SQL 中剔除，不建立缓存表或新块属性。

## 验收发现并修复

- 混合粘贴同时含图片文件与 HTML 时出现正文图片：上传附件时移除 HTML 图片，保留文字。
- 宫格摘要显示 Markdown 与块引用源码：使用原生 DOM 正文摘要，引用插入的锚文本约定保持原样。
- 历史接口返回只读 DOM，原先按可编辑节点读取导致 0 字：改为读取原生叶子块正文；同一真实历史版本读回 24 字。
- 快捷键移到轻墨根节点消费，避免到达文档级监听后才阻止冒泡。
- 大图序号在亮色背景不可读：序号与导航使用深色底，序号独立占位。
- 桌面统计柱被压缩到不足 44px：各布局统一最小触控宽度，图表支持横向滚动并保留键盘焦点轮廓。
- 21 张图片分页时宫格自动行高缩小、裁切详情：宫格按内容自然行高排列，维持纵向滚动及既有分页。
