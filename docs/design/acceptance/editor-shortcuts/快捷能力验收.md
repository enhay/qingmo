# 快捷能力验收与 Aa 工具栏

2026-10-15。结论：Aa 工具栏调整通过；编辑器整体快捷能力未全部通过，仍有四项内容保真缺陷。

## 范围与方法

使用 macOS Chrome 155、实际 Svelte 组件、思源 Lute 和合成笔记，宽度 1280、402、320px。agent-browser 启动独立浏览器；其原始 Cmd 事件连普通编辑框全选都未执行，随后用已安装的 Playwright 连接同一浏览器，校准普通 contenteditable 的 Cmd+A/B 后，再逐键输入和操作轻墨。没有用 `execCommand` 主动设置格式冒充按键结果。

快捷操作捕获真实 Composer 提交给 Repository 的参数；12 组代表性内容另经真实 MemoRepository 写入隔离思源 3.8.7，再以 `get()` 读回 Markdown 与 BlockDOM，交给实际卡片及编辑框消费。列表和软换行问题还执行了更新保存及再次读回。仅使用 `.scratch/kernel`，未修改个人笔记。

这不是 Windows/Linux、iOS/Android 真机或思源 Electron 全局快捷键冲突验收。中文输入法仅验证组合事件防误发送，不替代真实输入法候选确认。

## 通过项

| 操作 | 结果 |
|---|---|
| Cmd+B / I / U | 选中文字后加粗、斜体、下划线生效；关闭后续写普通文字；保存及原生读回保持 |
| Cmd+Z / Cmd+Shift+Z | 文本与格式撤销、重做生效，草稿同步更新 |
| 无序／有序列表按钮 | 新建列表、Enter 续项、空项 Enter 退出后续写普通文字通过 |
| 段落引用按钮 | 可开启及取消引用；连续 Enter 不自动退出引用，需使用按钮取消 |
| 标签补全 | 上下键选择、首尾候选选择、Enter 确认历史／新标签、Esc 关闭候选通过；确认标签不会直接发送 |
| Cmd+Enter / Ctrl+Enter | 非空内容提交一次；空内容不提交；模拟保存失败后保留输入和草稿 |
| 粘贴 | Cmd+V 粘贴普通文本保留字面内容，富文本保留粗体与段落 |
| 组合输入防误发送 | 合成 compositionstart 至 compositionend 之间 Cmd+Enter 不提交，结束后可提交 |

## 按用户截图调整 Aa

Aa 常驻第一层，上方弹出横向“加粗 / 下划线 / 高亮”；两种列表和段落引用仍在第一层，录音与发送保留。402px 下完整工具栏为单行，320px 自然换行，触控区域不小于 44px。

已验证宽窄／亮暗下三格式组合开启、逐项关闭、改变文字选区后再应用、点击外部关闭、Esc 关闭并恢复输入焦点、键盘打开后方向键选择和空格应用。提交参数与草稿内容符合选中的格式。

原“更多格式”失效已修复：旧菜单调用 `hiliteColor` 时，输入框祖先仍为 `inert=true`，选区为空，原生命令返回 `false`。新弹层位于 Composer 内，保持输入框可交互和编辑选区，不再借用 App 的模态菜单。

## 未通过：本轮未修改的编辑器问题

| 优先级 | 复现与影响 | 已定位原因与范围 |
|---|---|---|
| 高 | 新输入 `first` → Enter → `second`，编辑区两行，提交和数据库读回为 `firstsecond` | `src/editor/editor.js` 的 `serialize()` 在 P/DIV 后加分隔符，却未处理“裸文本后跟 DIV”的前边界；[输入](01-enter-before.png)、[保存后](02-enter-after.png)，隔离块 `20261015234015-en75i73` |
| 高 | 已保存列表全选 Cmd+B 再保存，原两项列表多出空项 | Lute HTML 的列表项间换行经浏览器加粗成为 UL 直属 B；`serialize()` 把 `node.children` 全部当 LI 输出。真实更新后仍有空项，块 `20261015234015-0kt9jj2` |
| 中 | Shift+Enter 初次保存为软换行，再次编辑保存后变为段落间空行 | BlockDOM2HTML 生成 `<br>\n`；序列化同时计算 BR 和其后换行文本，输出两次换行。块 `20261015234015-wb6ije1` |
| 中 | 手打 `~~strike~~`、`==mark==` 时输入框显示符号，发送后变删除线／高亮；单独 `---` 变为空 YAML 前置信息 | `escapeMarkdown()` 未转义这些 Markdown 构造，与星号、反引号、列表等已转义内容行为不一致；原生读回和展示已复核 |

四项均在现有编辑器序列化／净化路径内，修复主要涉及 `src/editor/editor.js`，需覆盖新输入、重新编辑及原生读回，不能只改卡片样式。此次用户要求验收及调整 Aa，未把这些独立修复混入工具栏改动。

## 尚未实现的快捷输入

`**文字**`、`*文字*`、反引号、链接语法、`- 空格`、`1. 空格`、`> 空格`、`# 空格`、三反引号并回车均未在输入时自动转换。Tab 移到下一个控件，不会缩进列表。这些与已有“所见即所得格式按钮”属于不同能力，未按已通过处理。
