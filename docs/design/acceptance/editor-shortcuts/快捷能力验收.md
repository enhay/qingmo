# 快捷能力验收与 Aa 工具栏

2026-10-15。结论：Aa 工具栏调整通过。当时发现的四项内容保真缺陷、格式内符号的宿主转换问题已于 2026-10-16 修复，输入时的 Markdown 快捷转换与列表 Tab 缩进同日补齐，`# 空格` 标题未做。

## 范围与方法

使用 macOS Chrome 155、实际 Svelte 组件、思源 Lute 和合成笔记，宽度 1280、402、320px。agent-browser 启动独立浏览器；其原始 Cmd 事件连普通编辑框全选都未执行，随后用已安装的 Playwright 连接同一浏览器，校准普通 contenteditable 的 Cmd+A/B 后，再逐键输入和操作轻墨。没有用 `execCommand` 主动设置格式冒充按键结果。

快捷操作捕获真实 Composer 提交给 Repository 的参数；12 组代表性内容另经真实 MemoRepository 写入隔离思源 3.8.7，再以 `get()` 读回 Markdown 与 BlockDOM，交给实际卡片及编辑框消费。列表和软换行问题还执行了更新保存及再次读回。仅使用 `.scratch/kernel`，未修改个人笔记。

这不是 Windows/Linux、iOS/Android 真机或思源 Electron 全局快捷键冲突验收。中文输入法仅验证组合事件防误发送，不替代真实输入法候选确认。

## 2026-10-16 保真修复

下表四项为 10-15 复现的缺陷，修复都在 `src/editor/editor.js`。核验用 Chrome 无头浏览器真实按键操作编辑区，内容经隔离思源 3.8.7 内核保存、`get()` 读回，再交给卡片渲染和编辑框再次编辑后二次保存；数据见 [保真修复数据](编辑器保真修复数据.json)，格式内符号、日期筛选与快捷转换见 [快捷输入与格式符号数据](快捷输入与格式符号数据.json)。

| 缺陷 | 原因 | 修复后 |
|---|---|---|
| `first` → Enter → `second` 保存为 `firstsecond` | 裸文本后跟 DIV 时没有段落前边界 | 段落前一兄弟为行内内容时补段落分隔；提交 `first\n\nsecond`，真实 Composer 提交一致 |
| 已保存列表全选加粗后多出空项 | Lute HTML 的列表间换行被加粗成 UL 直属 B，序列化把所有子元素当 LI | 载入时移除块间排版换行；序列化只把 LI 或有内容的节点当列表项，空白格式不再输出空的格式片段；读回 `- **a**\n- **b**` |
| 软换行再次编辑变为段落 | BlockDOM2HTML 的 `<br>\n` 被计为两次换行 | 载入时去掉 BR 后的排版换行；再次编辑保存仍为 `one\ntwo` |
| 手打符号发送后变成格式 | 转义未覆盖思源支持的其他行内与块语法 | 实测内核会转换 `~~`、`==`、`~下标~`、`^上标^`、`$公式$`、`~~~`、单独的 `---`；现转义 `~ ^ $`、连续 `=`、整行短横线及行尾单独的 `- + > # 1.`，格式内文字同样转义。内核读回均为纯文本，卡片原样显示，再次编辑稳定 |

同一根源的显示问题一并消除：编辑已有笔记时，Lute 排版换行在输入框 `pre-wrap` 下显示为段落、列表项之间的多余空行，软换行显示为两行。`a=b`、单个 `=`、`===` 内核不转换，保持不转义。

已验证不回归：引用块、松散列表、代码块（内部空行保留）、音频块及其属性、草稿重载；粘贴与载入共用这次的净化改动，但粘贴没有单独复测；现有 14 项测试、构建、产物语法检查通过。

**格式内符号**：加粗等格式里的 `~~x~~`、`$5$`、`==m==` 原先首次保存正确，但思源把格式片段导出 Markdown 时丢掉转义（`getBlockKramdown` 的 md 与 textmark 两种模式都如此），卡片渲染、再次编辑及手动转写都以这份 Markdown 为中间产物，结果变成删除线、公式或高亮。现在卡片渲染在宿主转换前用占位符保护格式内文字、转换后还原；编辑框改为从卡片 DOM 载入，原生引用和音频块按文档顺序放回，手动转写同样从 DOM 载入；可编辑判断在有 DOM 时只在确有公式时才拒绝 `$`。卡片显示、再次编辑、转写回写后读回均无误转格式，引用与音频块 ID 保留，待转写标记按预期清除。

仍有的宿主限制：移出轻墨（删除 `#轻墨#` 标签）会读取并回写宿主 Markdown，若该段含格式内的上述符号，回写后会变成真实格式。这一路径修改的是用户原有笔记，未在本次改动。

## 输入时的 Markdown 快捷转换（2026-10-16）

| 输入 | 结果 |
|---|---|
| `**文字**`、`*文字*`、`` `文字` `` | 打完闭合符号即变为加粗、斜体、行内代码，后续文字恢复普通；Cmd+Z 一次退回原符号 |
| `[文字](链接)` | 变为链接；仅接受 http(s)、mailto、思源块链接与 `#`，`javascript:` 等保持原文 |
| 行首 `- `、`* `、`+ `、`1. `、`3. `、`> ` | 变为无序列表、有序列表（保留起始序号）、引用；列表、引用或代码内不再嵌套转换 |
| 行首 ` ``` ` 或 ` ```js ` 后回车 | 变为代码块并记录语言；块内回车换行，可保留空行；末尾连续两个空行时再按回车退出 |
| 列表内 Tab / Shift+Tab | 缩进为子列表、取消缩进；列表外 Tab 仍移到下一个控件 |

两侧必须是空白或行首才转换，`2*3*4`、`a**b**c`、句中的 ` - ` 保持原文。只在直接键入时生效，输入法组合过程中不转换。嵌套列表保存后读回、再次编辑一致（有序子列表按序号宽度缩进）。真实 Composer 中与标签补全、Cmd+Enter 提交一同使用通过。

未做 `# 空格` 转标题：`#` 是标签入口，标题也不在速记编辑器支持的结构内，加入会改变速记可保存的内容类型，需要用户决定。
