# 价值澄清

方法来源：life-coach 的 values clarification 与 GROW，见 [来源说明](sources.md#价值澄清)。轻墨从已有记录进入，不额外启动一套教练问卷。

## 找到价值线索

从让作者感到自在、满足、不甘或羡慕的具体经历，以及愿意付出成本的选择中，寻找作者在保护什么。尽量沿用作者自己的词，不先拿一套价值词表给人归类。

区分：

- 目标是想达成的结果，价值是为什么这个结果值得追求。
- 说自己重视什么，和实际愿意为此付出什么，是不同的依据。
- 工作要求、经济压力或他人期待可能约束选择，不能直接当作作者认同的价值。

感受可以提出一个价值假设；反复选择和真实成本帮助确认它。不要单凭一项爱好或购物清单宣布“你真正重视的是……” 。

## 放回真实取舍

选一件具体决定，按 GROW 的思路理解：作者想得到什么；现实里有什么约束；当时还有哪些选择；什么小选择能更接近作者在意的方向。

价值之间确有冲突时，把两边的好处、成本和难处都写清。没有冲突就不制造冲突，不替作者给人生价值排永久顺序。明确区分作者当时想过的选项和现在建议的新选项。

## 怎么呈现

围绕最有依据的价值，写清“你在保护什么—哪些选择说明这一点—下次取舍时可以用什么问题判断”。让作者能够接受、修正或否认这个解释。

如果用户正在做决定，可给一个由作者自行调整的选择标准或很小的下一步。不要替作者承诺截止日期、打执行信心分或设置后续打卡。
