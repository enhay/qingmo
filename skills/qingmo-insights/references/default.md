# 默认洞察

方法来源：guided-journaling 的跨记录回顾与 reflective 模式，见 [来源说明](sources.md#默认洞察与-cbt)。用于理解作者，不急着给作者安排改进任务。

## 看什么

寻找记录中反复出现、却还没有被作者连起来的主题：什么情境让作者在意，怎样理解它，接着做了什么，以及后来有没有变化。情绪、愿望、具体行动和现实条件都可以成为线索。

只有一条记录时，从这条里最值得理解的地方展开：情绪与当时的期待有什么关系，一个模糊想法具体卡在哪里，或一件日常小事为什么让作者在意。关系不清楚就保留问题，不从一次事件推导长期模式，也不把普通生活强行解释为深层创伤。

区分三种情况：

- 同类情境下反复出现的反应，可能构成一个模式。
- 不同阶段的前后表述，可能是观点改变或方法调整。
- 同一时期保护不同东西的选择，可能是价值间的拉扯，也可能只是场景不同。

## 怎么理解

选最值得谈的联系，说明为什么把这些记录放在一起。先反映作者已经表达出的体验，再探索它可能意味着什么。让解释比原文多走一步，但每一步仍能指回记录。

主动看不符合解释的记录：原先的困难是否已经改善，某种做法在另一场景是否有效？给一个有依据的不同解释，避免把所有记录都装进同一个故事。

涉及作者没说出的动机时，保留询问和可能性。没有行动记录只能说“这些笔记里还没看到后续”，不能说作者从未行动。一次负面反馈也不能定义这个人。

## 怎么呈现

用一两个具体发现串起结果，每个发现自然包含依据和对作者的意义。可以点出矛盾，也可以指出已发生的成长；不要强求“隐藏创伤”或总是找到缺点。

有值得继续探索的地方时，结尾留一个贴近原文的问题；已经回应了作者的问题，就可以结束。只有记录明显指向一个可行的小改变、且它确实有帮助时，才给行动建议。作者只是想理解一段经历时，清楚的理解本身就是结果。
