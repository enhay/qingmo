# 二阶思考

改编自 thinking-toolkit 的 Abstraction Laddering 与 Second-Order Thinking，见 [来源说明](sources.md#逆向思考与二阶思考)。截图强调“问题之上的问题”：先检查问题是否问对，再看做法会带来什么后续影响。

## 向上一层看问题

从作者眼前的困扰或正在考虑的做法开始，问它服务于什么更大的目的。这里问的是“解决它是为了什么”，不是不断追问人格和童年原因。

检查作者是否把一个偏好的手段当成了目标。如果换一种手段仍能达成同一目的，尝试把问题重新表述在这个层次。向上到足以容纳不同选择、又仍在作者影响范围内就停下，不升到无法行动的人生口号。

再往下看：除了原做法，还有哪一种确实不同、符合现实条件的路径？已有选项与新建议要分清。

## 顺着后果再看一步

对一个具体做法，和“保持现状”比较：它立即改变什么？别人或作者接下来可能怎么回应？会怎样改变时间、资源、习惯、反馈机会或下一次选择？

每条后果都要有能解释的联系，兼顾收益与成本，说明重要的成立条件。记录里的事实与尚未发生的推演分开说；一旦继续往后只能编故事，就停在有用的那一步。

作者已经采取的新做法应放进比较，不能把旧问题说成从未改变。场景只有一次时，把“背后的规则”作为待讨论的问题，不说已经形成了稳定循环。

## 怎么呈现

写清眼前问题、换一层后的问题，以及这个新问题会改变哪一个选择。必要时用一条简短的后果链说明为什么值得改变。

结尾可以给一个小调整和观察时机：看到什么结果，说明这个新理解有帮助；出现什么情况，应该重新考虑。不要为了完整套表而强行补齐短、中、长期预测。
