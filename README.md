# 轻墨

轻墨是思源的本地速记插件。每条速记保存为带专属属性的原生超级块，每天放入一个独立文档；卡片流、标签、图片、搜索和统计读取这些块。手机端全屏；桌面端在思源标签页里以两栏布局打开，右侧栏沿用手机布局。

这是一期本地实现，尚未正式发布。声明最低版本为思源 3.8.5，具体本地实测与未验证范围以交付说明为准。

## 本地构建

需要 Node.js 22 或更新版本，无 npm 依赖，不需要安装依赖。

```sh
npm run build
```

构建生成 `dist/`，其中 `index.js` 已包含插件自己的模块，`siyuan` 由宿主提供。将 `dist/` 内文件打包即可得到插件包。

## 本地预览

```sh
npm run link -- <思源工作空间目录>   # 构建并把 dist/ 软链接为 data/plugins/siyuan-qingmo
npm run dev                         # src/、i18n/ 变化时自动重新构建
```

改动后重载思源界面即可看到新版本；首次链接后需在集市「已下载」里启用插件。插件目录已是实际目录时脚本会拒绝覆盖，请先手动移走。删除软链接即可取消链接。

## 手动安装

先备份工作空间，再把 `dist/` 内文件复制到目标工作空间的 `data/plugins/siyuan-qingmo/`，重启思源并在插件设置中启用。项目构建不会自动安装或修改个人笔记。

第一次使用需要选择笔记本。默认路径为 `/轻墨/{yyyy}/{MM}/{yyyy-MM-dd}`。调整笔记本或路径只影响之后新建的每日文档，不搬动既有记录。删除可通过思源文件历史恢复。草稿保存在当前设备的 localStorage，不随思源同步；已上传但未引用的图片使用思源资源清理功能处理。

安装自用前必须完成 V1–V3：双设备同日记录同步后均保留；iOS/安卓全屏键盘与安全区；冷启动输入、返回和杀进程草稿恢复。每日文档存在双设备同时修改的同步冲突风险，单机本地验收不能证明这些项目通过。隔离内核的 5000 条合成记录已测得首屏数据读取约 533ms、统计约 243ms，桌面侧栏刷新至绘制约 691ms；仍需真机端到端性能及连续四周自用验收。完整本地结果和截图在源码目录 `docs/design/acceptance/`。

一期不包含录音转写、AI、导入、付费授权或集市发布。

## 记录和查找

直接写内容即可，不必填写标题。输入 `#` 可以选择已有标签，`#工作/项目 ` 可以表达多级标签；Enter 换行，Cmd/Ctrl+Enter 发送。收起输入面板会保留本机草稿，重新打开可以继续写。

关键词按连续文本包含匹配，可以叠加标签、图片／链接类型和日期。标题下显示正在使用的条件，可逐项移除或清除全部；收起搜索框不会取消关键词条件。点击「全部笔记」或顶栏标题回到全部记录。热力图再次点击已选日期可取消日期筛选。

官方帮助的对照依据及功能边界见源码目录 `docs/design/flomo参考与交互细节.md`。AI 方法集中维护在 `skills/qingmo-insights/SKILL.md`，目前仍未接入插件。
