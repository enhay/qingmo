# 轻墨

轻墨是思源的本地速记插件。新写的速记保存为带专属属性的原生超级块，每天放入一个独立文档；已有笔记可以通过块菜单加入，或使用原生 `#轻墨` 标签收入卡片流，内容仍在原处。手机端全屏；桌面端在思源标签页里以两栏布局打开，右侧栏沿用手机布局。

当前包含一期速记功能，以及二期的已有笔记收录、每日回顾和随机漫步，尚未正式发布。声明最低版本为思源 3.8.5；二期本地验证使用 3.8.6，具体实测与未验证范围以交付说明为准。

## 本地构建

需要 Node.js 22.12 或更新的 22.x，或 Node.js 24 及以上。使用锁定版本的 Svelte 5、Vite 和官方 Svelte 插件构建。

```sh
npm ci
npm run build
```

构建生成 `dist/`，其中 CommonJS `index.js` 包含插件组件和自己的模块，`siyuan` 由宿主提供；样式、翻译和 AI 方法资源一并打包。将 `dist/` 内文件打包即可得到插件包。

## 本地预览

```sh
npm run link -- <思源工作空间目录>   # 构建并把 dist/ 软链接为 data/plugins/siyuan-qingmo
npm run dev                         # src/、i18n/ 变化时自动重新构建
```

改动后重载思源界面即可看到新版本；首次链接后需在集市「已下载」里启用插件。插件目录已是实际目录时脚本会拒绝覆盖，请先手动移走。删除软链接即可取消链接。

## 手动安装

先备份工作空间，再把 `dist/` 内文件复制到目标工作空间的 `data/plugins/siyuan-qingmo/`，重启思源并在插件设置中启用。项目构建不会自动安装或修改个人笔记。

第一次使用需要选择笔记本。默认路径为 `/轻墨/{yyyy}/{MM}/{yyyy-MM-dd}`。调整笔记本或路径只影响之后新建的每日文档，不搬动既有记录。删除可通过思源文件历史恢复。草稿保存在当前设备的 localStorage，不随思源同步；已上传但未引用的图片使用思源资源清理功能处理。

安装自用前必须完成 V1–V3：双设备同日记录同步后均保留；iOS/安卓全屏键盘与安全区；冷启动输入、返回和杀进程草稿恢复。每日文档存在双设备同时修改的同步冲突风险，单机本地验收不能证明这些项目通过。一期隔离内核的 5000 条合成记录已测得首屏数据读取约 533ms、统计约 243ms，桌面侧栏刷新至绘制约 691ms；仍需真机端到端性能及连续四周自用验收。完整本地结果和截图在源码目录 `docs/design/acceptance/`。

本轮不包含录音转写、AI 视角、flomo 导入、付费授权或集市发布。录音转写（用户自带腾讯云密钥）与 AI 洞察已列入二期计划，尚未实现。

## 收录已有笔记与回顾

在思源编辑器的块菜单中，进入「插件 → 加入轻墨」即可收入当前块；也可以直接写原生 `#轻墨` 标签。列表、搜索和统计以块 ID 去重，标题只收入标题本身。外部内容的卡片显示来源文档，点击可定位原块。

在文档顶部添加「轻墨」标签，会把整篇笔记收入为一张卡片，显示标题和正文预览；点击标题或菜单可回思源打开、编辑。整篇收录时内部卡片暂不重复显示；移出只去掉文档上的「轻墨」标签，内部单独收录的内容恢复显示，正文及其他标签保留。

外部卡片的「移出轻墨」会保留原块；手动加入时清除轻墨属性，标签收入时去掉收录标签，同时使用两种方式时会在确认后清除两者。段落和超级块可在轻墨中编辑；段落转换为多段或列表等结构时，请在思源编辑器中完成，避免内核单段落写回丢失内容。

卡片流顶部和侧栏可进入回顾。每日回顾在同一设备、同一天保持已有抽取顺序，数量可以设置；随机漫步每次翻开一条。两个视角都在本地运行，不使用 AI，也不发送笔记到外部服务。二期见 [实施计划](docs/plans/2026-10-12-phase-two.md) 与 [本地验收](docs/design/acceptance/二期本地验收.md)。

## 记录和查找

直接写内容即可，不必填写标题。输入 `#` 后，候选按已输入文字匹配历史标签，支持名称中间匹配、多级标签和大小写不敏感匹配。点击候选，或用上下键选中后按 Enter，即可复用；没有主动选择候选时，Enter 确认自己输入的完整标签名，不自动套用第一个相似标签。完成标签后继续写正文；普通正文 Enter 换行，Cmd/Ctrl+Enter 发送。收起输入面板会保留本机草稿，重新打开可以继续写。

卡片正文可直接选中文字，右键选择「复制所选文字」；未选中文字时，右键打开卡片操作菜单，其中「复制文本」用于复制整条正文。选择文字本身不会自动复制。

卡片菜单的「历史版本」复用思源文件历史。左侧选择时间，右侧预览内容；可以恢复这一条笔记，或另存为新的速记。修改前会留存并核对原内容，恢复不会回滚同文档的其他笔记；已有未保存草稿时会先确认是否替换。复杂原生结构请在思源中处理。历史的生成与保留期限由思源管理，同秒记录可能合并，图片依赖原资源文件；未发送草稿不计入历史。

卡片操作采用纯文字菜单。输入框直接显示加粗、下划线、高亮、列表和引用的效果；格式按钮作用于所选文字或接下来输入的内容。列表中 Enter 继续下一项，空项 Enter 退出列表。编辑器宽度足够时直接展开格式工具，窄屏才收起到「更多格式」。

侧栏「全部笔记」的子筛选默认收起。图标平时保持四格，悬停显示右三角，点击图标展开后显示倒三角；点击文字回到全部记录。展开状态在当前页面刷新筛选结果时保持。

关键词按连续文本包含匹配，可以叠加标签、图片／链接类型和日期。标题下显示正在使用的条件，可逐项移除或清除全部；收起搜索框不会取消关键词条件。点击侧栏「全部笔记」回到全部记录。顶部标题打开排序与来源菜单：按创建时间从新到旧或从旧到新排列，来源可选全部、轻墨速记、收录笔记；来源条件可以单独清除。热力图再次点击已选日期可取消日期筛选。

官方帮助的对照依据及功能边界见源码目录 `docs/design/flomo参考与交互细节.md`。AI 方法集中维护在 `skills/qingmo-insights/SKILL.md`，目前仍未接入插件。
